## §1 越剧《李清照》（1999）：七场结构与唱段表

**主线**：李清照一生七个断面——少女得词、青州婚趣、南渡重逢、明诚病亡、婺州被骗、酒馆认领自己、垂暮再上秋千。**结构法是"一场一首词"**：每场用一支李清照的词作场名，幕内唱该词开场、再唱该词（或另一支）收场，**词是场的边框，戏在框里演出这首词是怎么写出来的**。**首尾同用《如梦令》，秋千同上同下，全剧成一个闭环。** 剧末自注："本剧参照 1991 年与徐进合作的越剧电视剧剧本《人比黄花瘦》"（p0114）。

### 1.3 程式清单

- **自报家门**：**无**。全剧无一人自报，身份由【字幕】＋对白交代（"这位乃是江南词坛俊杰"）。
- **定场诗**：**一处变体**（p0094）——四公子上场一人一句(念)七言："十月江南菊花黄／骚人赏秋正繁忙／谁道国势已吃紧／秦淮两岸好风光。"**定场诗被拆给四个人念，同时完成上场、点时令、点地点、点人物气质四件事。**
- **下场诗**：**全剧无**；取而代之的是每场收尾的**幕内唱李清照词**——功能位相同（点收本场、留余味），载体从"念的诗"换成"唱的词"。
- **背供**：李清照全剧没有；全卷只有《梨园天子》两处标"（暗唱）"。
- **幕内唱／幕后合唱**：15 处，本剧最重的程式。四种用法：①开场定调（《如梦令》）；②场中插入（第三场《一剪梅》上下片分插在重逢前后）；③收场点题（《孤雁儿》下片）；④**合头**（第五场"是朋亦是友"重复主角刚唱的四句）。
- **上下场**：只写【…上】【…下】，无锣鼓、无引子、无上场诗。
- **道具贯穿**：**秋千**（第一场上、第七场再上，中间五场不出现）＋**《金石录》书稿**（第四场合著→第五场抛撒→第七场完成）。两条贯穿链对齐首尾。

### 1.4 摘唱词（示范什么）

**(1) 七字同字头四句 ×2 组，是本卷扩段的主要手法**（p0086，第一场）：

```
手捧着《新词集》墨香阵阵，
又是喜又是惊心绪不宁。
早听闻赵明诚精深学问，
未料及竟是我词中知音。
觑着他心儿怦怦跳；
觑着他脸儿泛红云；
觑着他胆儿忽然大；
觑着他语儿变得轻。
赵公子呀——
赋新词随心遣兴，
小使俩何劳上心。
不避讳花园聚会，
嘱丫头引进后门？
```
——**十字句四句叙事 → 七字句四句同字头写"看"的动作 → 七字句四句同字头写"决定"**。同字头（"觑着他"）代替了京剧的垛句：**不缩短字数，只重复句头。越剧的排比是齐言的，不是垛的。**

**(2) 全剧最长段的分层**（p0104，第五场）：

```
明诚啊，
谁怜你一副傲骨葬异乡，
谁怜你空怀壮志和抱负；
谁怜你清白名声被玷辱；
谁怜你书生中年一命休！
莫名冤案错、错、错，
高节蒙污羞、羞、羞！
……
罢了！
献什么收藏，
追什么行舟，
澄什么疑案，
辩什么冤由，
且把珍宝来看护，
切莫使战乱年月一件丢。
```
——一段之内**三换句式不换韵**（十字同字头 → 七字带叠字 → 五字同字头 → 十字收）。"错、错、错／羞、羞、羞"直接化用李清照本人《钗头凤》式的叠字——**人物是词人，所以她的唱词可以比别人更文。**

**(3) 二字断顿，全卷最短句式**（p0107，第五场）：
```
国破！家毁！夫丧！物尽！
一连串的变故，
一回回的伤心，
一重重的劫难，
我要呼喊一声不公平！
```
——**四个二字词并列当一句用**，下接三句"一×一×"七字排比。这是越剧唱词里最接近"垛"的形态，但**仍不是京剧那种 3 字顿连缀的大垛**。

**(4) 由白转唱的接口——称呼语**（全卷通例，此处 p0091）：
```
李清照　明诚，国家用人之际，你就领命上任吧。
……
赵明诚　谢夫人。
　　　　（唱）一纸官文不由己，
　　　　　　　无奈上任去莱州。
```
——**每段唱的前一行几乎都是一个称呼语或一句短白**（"明诚啊——""赵公子呀——""夫人啊！"）。与吴梅所记《惊梦》、《朝阳沟》全剧通例并列，**这条已可从建议升格为两体系都写的硬规则**。自检动作完全一致：**每段唱的前一行是不是一个称呼语？**

**(5) 引现成词作入唱——本剧独有的技术**（p0083、p0114）：全剧 15 处幕内唱中，**13 处唱的是李清照本人的词原文**（如梦令 ×2、浣溪纱、点绛唇、凤凰台上忆吹箫、一剪梅上下片、夏日绝句、添字采桑子、孤雁儿、行香子上下片、声声慢上下片、鹧鸪天），1 处唱欧阳修《玉楼春》（由赵明诚当场唱）。**做法：词原文只做幕内唱与场名，人物在场上唱的一律是新写的越剧唱词；两者不混排。** 写传主是诗人／词人的戏时，这是一份现成模板——**原作当框，新词当肉，不让原作抢场上人物的嘴。对媒介不限。**

## §2 越剧《真假驸马》（1986 创／2004 改）：六场结构与唱段表

罗怀臻**第一部上演的剧本**，1986 年应约为上海越剧院作、同年该院首演；次年他被上海越剧院作为人才引进，由江苏淮阴迁居上海。⚠️ **本卷收的是十八年后的修改本，不是首演本；书里不收旧稿，两版差异无从对读。**

**主线一句话**：状元驸马董文伯坠崖"身死"，公主为保董家荣华，命其孪生弟文仲顶名冒充驸马；三年后文伯生还，全家为保住这个已经长成的假局，在金殿之上**合力指认他为疯子**，他被迫承认"我是疯子"以求活，仍被赐死；母亲抢饮毒酒代死，文仲咬断舌头，匡正挂冠而去。

**人物表下的一行注是全剧的技术前提**（p0006）："（注）董文伯、董文仲系孪生兄弟，**剧中由同一演员兼饰**。"——**这是为越剧女小生度身的结构**：一个演员演两个人、两种气质，且二人在第六场之前从不同台。**"孪生＋顶替"这个题材本身就是为一赶二的行当条件生出来的。**

### 2.3 程式清单

- **自报家门**：无。**定场诗**：无（匡正上场用（唱）代替，配角用独白代替）。**下场诗**：无；代之以**下场唱句**（第二场"且含住千行泪／咽苦涩吞伤悲"两句五字，唱完即下）。
- **背供**：全剧无标注。第六场的"一语双关"（公主对文伯"你若不是疯子，怎敢在金殿上胡言乱语？"，剧本明注"（盯视他，一语双关地）"）是**背供的替代物**：不向观众说，而是**当着所有人说两层意思**。
- **内唱上场**：第六场文伯被宣，先在幕内唱一句再上（p0033）——全卷唯一一次保留"导板上场"的形制。
- **幕内唱**：14 处，四种功能：主题歌（首尾）、场面交代（"挑起灯笼四处奔"）、**心理旁白**（替公主唱她不便唱的念头）、**与场上白咬合**（"金口玉言——"／皇帝白："宣！"／【幕内接唱："宣、宣、宣"】，p0033）。**第四种是全卷唯一。**
- **一赶二**：孪生兄弟同一演员；第六场文伯被斩的锣声中文仲冲上"手指断舌、对皇帝比比划划"——**两个角色在同一场出现但不同时露脸**，靠"哑"与"被抬下"回避。

### 2.4 摘唱词

**(1) 七字单句对切八句——越剧对唱的基本形态**（p0010，第一场）：
```
董文仲　（唱）寸寸儿移步慢、慢、慢，
公　主　（唱）泪珠儿滴落二弟肩。
董文仲　（唱）兄长也曾背嫂嫂，
公　主　（唱）那是调皮和喜欢。
董文仲　（唱）兄长背的是团聚，
公　主　（唱）兄弟背的是离散。
董文仲　（唱）从此兄嫂两不见，
公　主　（唱）想到离散情何堪？
```
——**一人一句、同韵到底、后句必接前句的词**（背嫂→背的是团聚→背的是离散→两不见）。与豫剧"二八连弹"是同一个技术，**越剧无专名、也无板式标注，编剧能控制的只有"一句一换人"和"句句咬字接力"这两件事**。自检：遮掉人物名，句子是否仍连成一段完整的话？

**(2) 三字头＋十二字长句四连——全卷唱词的最高点**（p0023，第三场）：
```
盗我者，是我一胞同生的亲兄弟；
欺我者，是我牵肠挂肚的老母亲；
负我者，是我日思夜想的结发妻；
伤我者，都是我相敬相爱的自家人。
结发妻子叫嫂嫂，
孪生兄弟称兄尊。
我挣扎回来图什么，
如今是死不算死，生不算生。
```
——①**三字提头＋长句**是越剧突破七字十字的主要出口（每句 12–13 字）；②四句只有第一、四句押人辰——**上句不押、下句押的原则在长排比里被放宽成"首尾押、中间任意"**；③紧跟两句七字把长句拉回齐言——**长短句必须回到齐言收**。

**(3) 三字顶针（联珠）六连——全卷唯一**（p0026，第四场）：
```
翘首望，思亲人，
思亲人，更伤情，
更伤情，泪纷纷，
泪纷纷，暗呻吟，
暗呻吟，一声声，
一声声，唤娘亲！
```
——三字句两两一行，**后一行的头＝前一行的尾**。这是越剧从弹词、唱书带进来的格式，不需要板式支持，纯靠字面递进；写"一个人在夜里越想越苦"的段落可直接取用。**用一次就够，本卷只出现这一次。**

**(4) 大收煞跪两个人、换一次韵**（p0039–0040，第六场）：对母用人辰（心、情、亲、恨、平），对妻用言前（涟、恋、冤、田、面、甘）。**一段大唱里换对象就换韵**——与"根据人物性格定韵"并列，这里是**根据听者定韵**：同一个人唱，换一个跪的人，换一个韵部，观众耳朵立刻知道转向了。**这是本卷提供的、前面几本材料没有的一条。**

**(5) 高潮场几乎不唱**（第六场，唱段标记仅 6 处，其中 2 处是幕内唱）：金殿对质——举出"忠信"命题、掌中痣的位置、皇后的逆转、四人同呼"疯子"——**全部用白**。唱只出现在四个位置：内唱上场、皇帝的自我说服、匡正的变节、文伯的"梦方醒"与临终。**越剧的"当唱不唱"不一定是毛病**：事理辩驳、身份举证、群体压迫这三类内容用白更快；**唱留给"一个人对着另一个人交心"。**

### 3.6 E 剧本体例（与京剧本的对照）

| 要素 | 越剧本子 | 对照：京剧本子（沙家浜／白蛇传／锁麟囊） |
|---|---|---|
| 板式 | **不标**（全卷 0 处） | 每段必标 |
| 唱 | 人物名后 `（唱）`，续唱用 `（接唱）`；另有 `（合唱）(齐唱)(伴唱)(暗唱)(内唱)(齐诵)` | 板式标记本身即唱的标记 |
| 白 | **不加任何标记**（"有标记的是唱，没标记的是白"） | 常标"白"或以板式有无区分 |
| 舞台提示 | **用单侧方括号"【"开头、不闭合**，独占一行 | 圆括号或方括号成对 |
| 分场单位 | 场／幕／回（本卷三种都有） | 场 |
| 场名 | 两类：有名（真假驸马；李清照七场全用**李清照本人的词牌**）、无名（梨园天子、蛇恋、梅龙镇只编号） | 场名或编号 |
| 时空交代 | **【字幕：……】**（全卷 8 处，《李清照》独占 6 处） | 自报家门、定场白 |
| 人物表 | 列名＋一句身份注；《真假驸马》表末加演出注 | 常标行当 |
| 行当 | **一律不标** | 人物表或剧首标行当 |
| 锣鼓、穿戴、检场 | **一律不写** | 翁偶虹本要写（总讲） |
| 落款 | 剧末标创作年（＋修改年）、改编来源注 | 前言／后记 |

**一句话**：越剧本子＝**场（或幕／回）＋【单括号舞台提示】＋人物名＋（唱）／无标记的白＋【字幕】交代时空＋幕内唱包边**，没有板式、没有行当、没有锣鼓。**编剧交出的是字句与情绪，不是腔与板**——与京剧编剧"交字句、板式与锣鼓"并列，**必须两份并写，否则会被读成"板腔体的剧本体例只有一种"**。

### 3.7 F 程式取舍（当代新编越剧通例）

- **删**：自报家门（全卷 0 处）、下场诗（0 处）、锣鼓／穿戴／检场提示（0 处）、板式标注（0 处）、行当标注（0 处）。定场诗只剩 1 处变体（p0094 四公子一人一句念七言）＋1 处念吟混排（p0122 钱谦益"一十六载林下困……（吟）天下大事少烦心"）。
- **留**：上下场（【…上】【…下】，无锣鼓）、**圆场**（2 处，且《梨园天子》p0047 给"圆场"加了引号，说明作者知道这是程式术语）、舞蹈身段（8 处）、**内唱上场**（1 处，p0033）、**背供**（2 处，全在《梨园天子》第五场，标"（暗唱）"，且**只用于猜疑**）。
- **增**：【字幕】（8 处）、**幕内唱／幕后合唱／伴唱**（7 部皆有，已是体例的一部分，四种功能：主题句包边／场面交代／心理旁白／合头）、**主题歌**（《蛇恋》长短句十句四次原样重复）、**评书人**（《青衫·红袍》四回前后上下场，作者直接露面）、**多表演区与舞台旋转**（p0025"多个表演区"；《柳如是》五幕全用"舞台旋转，场景迁移"）。

### 3.8 G 本卷支持不了的六件事（reference 必须留空）

1. **越剧板式表**——四工调／尺调／弦下调／二凡／流水／嚣板一个没有出现，本卷不提供任何板式与情绪、字句的对应。**这是越剧附录最大的空格**，须另找越剧音乐书或带谱的演出本。
2. **韵辙分部字表**——只能归纳出"常用哪几个韵部、哪些互混"，**没有分部字表**。**不要把京剧十三辙或豫剧中州韵套上去。**
3. **流派与字句的关系**——袁派、范派、傅派、尹派等一字未提。
4. **传统骨子老戏的写法**——本卷 7 部全是 1986 年以后的新编本，**归纳出来的是当代新编越剧的写法**；《梁祝》《红楼梦》《碧玉簪》一类传统本的字句与用韵，本卷无从旁证。
5. **首演本与修改本的差异**——《真假驸马》（1986→2004）、《蛇恋》（1993→2003）标了修改年，**书里不提供旧稿**。若日后取得首演本，最值得比的是：场次有无增删、唱段位置有无移动、**改的是字还是结构**（对照《沙家浜》两版差异的读数"改本不动结构只动字"）。
6. **唱腔、过门、伴奏、调门**——按总则一律不进 skill，本卷本来也一个字没有。

**《梅龙镇》句长递减原文**（p0231–0232）：
```
正　德（唱）我要孩儿常欢乐，
皇太后（唱）我要孙儿读书忙。
正　德（唱）要他知疾苦，
皇太后（唱）要他驭万方。
正　德（唱）不失本真，
皇太后（唱）先学端庄。
正　德（唱）懂得善恶，
皇太后（唱）识得忠良。
正　德（唱）天性！
皇太后（唱）国邦！
```
——**七字→五字→四字→二字**，一人一句，一韵（江阳）到底，逐句对仗。与豫剧"狗撕咬"（吵架专用、有板式名）并列：**递减在越剧里表达的是"两人越逼越紧、都不肯让"，不必是吵架；越剧没有板式名，编剧只能靠字数做出这个效果——字数本身就是越剧的板式。**

## §7 越剧卷卷后语（一手创作记录）

**卷后语 8 条（p0264）是越剧部分唯一的一手创作记录：**

1. **《真假驸马》**：1986 年应约为上海越剧院创作，同年该院首演。"**它也是我第一部上演的剧本。**"翌年上海越剧院把他作为人才引进，从江苏淮阴迁居上海。→ 与剧末落款"1986 年创作／2004 年修改"合看：**本卷收的是十八年后的修改本，不是首演本**。
2. **《梅龙镇》《青衫·红袍》**："我专为章瑞虹度身定做的，也是由上海越剧院首演。瑞虹是我曾经的生活伴侣、艺术的永久知音。这两部剧本也都凝结着她的情感、智慧和汗水。"→ **全卷唯一写明"为演员度身"的两部**；两剧的共同点（男角、一赶多、大段对唱）即"度身"的具体内容。
3. **未收的越剧作品**：另创作或合作《西施归越》《风月秦淮》《紫玉钗》及越剧电视剧《真假驸马》《人比黄花瘦》《秦淮烟云》等。→ **同一题材跨剧种重写是他的常态。**
4. **《梨园天子》**：由南京市越剧团首演（非上海越剧院）。
5. **《柳如是》**：缘起自与纪乃咸合作的《风月秦淮》，"后来重新创作为汉剧《柳如是》，现在仍以越剧的面貌收录"。→ **一个本子三种形态**；收进文集的是"越剧的面貌"，不是最新的汉剧本——**作者自己做了一次体裁回译**。
6. **《蛇恋》**：原应浙江省小百花越剧团约请创作，1994 年以《白蛇与许仙》剧名首演；后为浙江宁波市越剧团改写并易名《蛇恋》。→ **易名即易主题**：从"白蛇与许仙"（两个人的事）改成"蛇恋"（一条蛇要做人这件事）。
7. **《青衫·红袍》**："系与龚雄合作。"（剧末注作"龚孝雄"，p0263，**两处署名不一致，按剧末为准并存疑**。）
8. 《李清照》卷后语未提；剧末自注"**本剧参照 1991 年与徐进合作的越剧电视剧剧本《人比黄花瘦》**"（p0114）。徐进即越剧《红楼梦》编剧；**电视剧本→舞台本的回改**，与第 5 条的跨剧种回改并列成一组"同一素材的多次形态转换"。
