## 一、设计原则例表（Ch2：前提 vs 设计原则）

| 作品 | 故事前提（发生了什么） | 故事设计原则（用什么形式讲） |
|---|---|---|
| 《教父》 | 一个黑手党家族内部的运作 | 运用经典童话故事的策略，呈现三个儿子中最小的儿子成为新的"君王" |
| 《窈窕淑男》 | 一个演员找不到工作，乔装成女人，却和同剧的女演员坠入爱河 | 让一个男性沙文主义者过女人的生活 |
| 《公民凯恩》 | 一个富裕报业大亨一生的故事 | 透过多位故事讲述者的叙述，呈现不可能全部知道的某人的一生 |
| 《摩西》 | 一位埃及王子发现自己是犹太人，带领族人摆脱奴隶生涯 | 一个不知道自己身分的男子，带领族人追寻自由，并接受新的道德律令，这些律令也重新定义他与族人的身分 |
| 《圣诞颂歌》 | 三个幽灵探访一名吝啬老人，让他重新领略圣诞精神 | 一个人在圣诞前夕被迫检视过去、现在与未来，从而重获新生 |
| 《骗中骗》 | 两个骗术高手诈骗一名富翁，这个富翁此前杀害了他们的朋友 | 用骗术来讲述这个有关骗局的故事，骗倒了故事中的对手，也骗倒了观众 |
| 《四个婚礼和一个葬礼》 | 一名男子爱上一名女子，但两人先后与他人订婚 | 一群朋友在寻找结婚对象的过程中，经历四次乌托邦（婚礼）和一次地狱时刻（葬礼） |
| 《相逢圣路易》 | 一名年轻女子与邻家男孩坠入爱河 | 一个家庭在一年当中的成长，透过四季里发生的事件来呈现 |
| 《生活多美好》 | 一个男子准备自杀时，天使让他看到如果他不曾存在，世界会是什么模样 | 透过假设，呈现一个人从未存在时一座城市乃至一个国家会变成什么模样，藉此显现个人的力量 |
| 《长日入夜行》 | 一个家庭面对母亲的毒瘾问题 | 一个家庭从白天走进黑夜，面对往日的罪恶与幽灵 |
| 《尤利西斯》 | 一个男子在都柏林一天的生活 | 一则现代奥德赛式的游历故事，发生在城市、一天之内；期间一名男子找到了父亲，另一名男子找到了儿子 |
| 《哈利·波特》系列 | 一个男孩发现自己有魔法能力后，到一所魔法学校上学 | 一个有魔法的王子到一所培养魔法师的寄宿学校上学，在七个学年中学着成为男人和国王 |

关键句（Ch2）：**"所有故事都有故事前提，但只有好的故事有设计原则。"**／"故事设计原则＝故事发展过程＋具独创性的手法。"

## 二、步骤 1 例：《卡萨布兰卡》《窈窕淑男》（Ch8）

> 真实自我的揭露、需求和欲望代表主角在故事中整体转变的幅度。这是第二十、第三和第五步骤的结合……从故事的这个框架着手，我们首先确立剧情的终点。

**《卡萨布兰卡》**：真实自我的揭露——瑞克体会到，不能只因爱情受挫就放弃为自由而奋战。心理需求——克服对伊尔莎的怨恨，重新找到活下去的理由，并重拾对心中理想的信心。道德需求——不再损人利己。欲望——让伊尔莎回到自己身边。对自己的错误想法——瑞克认为自己是活死人，世事与己无关。

**《窈窕淑男》**：真实自我的揭露——麦可体会到他只把女人当成性爱目标，因此算不上真正的男子汉。心理需求——克服对女性的傲慢，学习真诚付出与接受爱。道德需求——不再说谎，不再利用女性达到目的。欲望——赢得同剧女演员茱莉的芳心。对自己的错误想法——麦可认为他对女性的态度得体，对女性撒谎也没关系。

框架三问（Ch8）：①主角在故事结尾会学到什么？②他在开头知道些什么（没有角色是一片空白，他必有特定信念）？③开头有些什么谬误？

## 四、幽灵（Ch8 步骤 2）

> 大部分作者都熟识"背景故事"这个术语……观众并不是对发生在主角身上的所有事都感兴趣，他们只对基本要素有兴趣，因此采用"幽灵"一词会好得多。故事中有两种幽灵。第一种且最常见的是以往发生但至今仍萦绕着主角的事件。这个幽灵是暴露在外的伤口，往往是主角心理层面与道德层面弱点的来源。……你也可以把第一种幽灵想象为**主角内在的对手**。这是一种巨大的恐惧，让主角无法投入行动。从结构上来说，幽灵的作用就像与欲望抗衡的力量。主角的欲望推动他向前，幽灵却把他往后拉。

例：哈姆雷特（叔叔弑父娶母，第一页之前的幽灵，前几页真幽灵现身索债）；《生活多美好》乔治·贝利（欲望是出去闯荡，幽灵是担心自己一走，暴君波特会怎么对待朋友与家庭）。第二种幽灵：主角起初活在宛如天堂的世界，受攻击后一切改变（《相逢圣路易》《猎鹿人》）。

开场纪律（Ch8）："很多作者尝试在第一页就告诉观众主角的一切，包括他为什么及如何为幽灵所苦。这一大堆信息其实会将观众推离故事。你应该反过来，试着先保留关于主角的许多信息……观众会想：'这里发生了一些事，我要找出那是什么。'"

## 五、四角对立四条关键特色（Ch4）

1. **每个对手应使用不同方法来攻击主角的重大弱点。** 对手的核心目的就是攻击弱点，区分对手的第一种方法是攻击方式各不相同；"这种技巧让所有冲突都能与主角的重大缺陷产生有机连结"，四角同时是整个群体的缩影。
2. **把每个角色置入冲突**：与主角有冲突，也与其他每个角色都有冲突——"透过四角对立……可以创造和建构的冲突数量倍增"。
3. **所有四个角色的价值取向全部置入冲突**："不要只赋予每个角色一种价值取向。为每个角色设想他可能信守的一组价值取向"；并"找出每种价值观的正向和负向形式"——相同价值观的正负形式如：坚决的与具侵略性的、诚实的与不够敏感的、爱国主义的与刚愎自用的，由此看出角色为信念奋斗时最可能在什么情形下犯错。
4. **尽量将角色推向每个角落**——差异最大化。

原书例：《哈姆雷特》《美国丽人》《呼啸山庄》《樱桃园》（逐角归位表与价值组见原书第四章图表）。

## 六、道德议题基本策略全链（Ch5）

价值取向：主角从一套信念和价值观起步 → 道德弱点：开头就以某种方式伤害别人（并非邪恶，只是受弱点影响，或不知道正确待人方式）→ 道德需求 → **第一次不道德行动**（几乎立刻采取，是主角基本道德缺陷的第一个证据）→ 欲望（目标导致与对手直接冲突，对方有同样目标、截然不同的价值取向）→ 驱动力 → 不道德行动（前段和中段主角通常败给对手，为胜利开始不道德行动）→ 批判（其他角色对其手段的批判）→ 合理化（主角辩解）→ **盟友的攻击**（最亲近的朋友指出他不对）→ 执迷不悟的驱动力（新的启示刺激下，为成功愿意做任何事）→ 不道德行动变本加厉，批判与合理化同步加强 → 主题在**四处**被领悟：对决（价值取向分胜负）；针对对手的最后行动；道德层面的自我揭露（对决的严酷考验催生）；道德层面的抉择（在两种行动之间选择，显示自我揭露为真）；主题的揭露（"其实是观众关于一般人应当如何待人处世的体悟……规模远比几个角色大得多"）。

力量平衡反例（Ch5）：亨利·詹姆斯《一位女士的画像》——伊莎贝尔自始至终自欺，面对的是擅于算计的奥斯蒙德，力量失衡，道德议题因而减弱。

## 七、场景编排例（Ch9）

> 场景编排更普遍的名称包括：场景清单、分场大纲，或分场纲要。它是撰写完整故事或剧本之前的最下一步。……试着用一句话来描述每个场景。……每个场景只列出单一的、必要的行动。接下来，在场景描述旁列出与它相关的所有结构步骤（如欲望、计划或看似落败）。有些场景可能附上这样的辨识标签，但很多场景没有这么做。

《教父》四场例（原文）：
- 麦可在医院中救了老教父，让他免遭暗杀。
- 麦可指控警官麦克鲁斯基为索洛佐效力；麦克鲁斯基以拳头相向。
- 麦可表示要消灭麦克鲁斯基和索洛佐。
- 克莱门萨教麦可如何消灭麦克鲁斯基和索洛佐。

三个修改动作（Ch9 原文顺序）：①**重新安排场景顺序**（先排整体进行序列，再查个别场景的并置）；②**合并场景**（"有时作者创造新的场景只是为了安排一句好的对白"）；③**检查删减或增加**（"赘肉愈少愈好……一旦减去所有赘肉，你可能发现场景编排当中有些断层，必须填上全新的场景"）。规模参考：好莱坞电影平均 40–70 场。
