**从本表推出的三条技术（p0174）**：
1. **一折之中移宫换韵是合法的，但必须因排场变动、剧情改换**（〈定情〉〈密誓〉〈埋玉〉三例，见 reference-taoshu.md §4e 末段）。
2. **北曲一折限一人唱的通例可以变通**：〈觅魂〉北仙吕全套前半净唱、后半末唱，「虽与北曲全折限一人唱之通例不合，然**此种长套之曲一人之力决不能唱毕，出神另易角色究是通幽一人**，故虽变通古人成法而仍不背于古。**非深明曲理者不能有此创举也。**」
3. 总评：「**其选择宫调、分配角色、布置剧情，务使离合悲欢错综参伍，搬演者无劳逸不均之处，观听者觉层出不穷之妙。自来传奇排场之胜无过于此。**」

**排场交替律（p0169，两体系通用）**：
> 「若第一折生唱、第二折旦唱，则**第三折必须用阔口或同场热闹之剧**；若慢曲长套二三折之后，**必须间以过场短剧或丑净所演之谐剧**。」

**生旦出场位（p0167）**：历来传奇「大都以**一生一旦**为全部之主」（《浣纱》范蠡西施、《紫钗》李益霍小玉、《牡丹亭》柳梦梅杜丽娘、《红梨》赵汝舟谢素秋、《桃花扇》侯方域李香君、《长生殿》唐明皇杨贵妃），「此生旦为全部传奇之主脑，**必须于第二折及第三折出场**。传奇之第一折皆说明大意，故其**第二折实第一折、第三折实第二折**也。」**例外并存**：《邯郸梦》以老生（卢生）为主、《钧天乐》以老生（沈白）小生（杨）为主，「作者苟能自出心裁、独摄奇境，**正不必拘守古人之成法也**」。

**为什么文人写的传奇不上演（p0166–p0167）**：「情节奇矣、词藻丽矣，不合宫调则不能付之歌喉；宫调合矣、音节谐美，**不讲排场则不能演之氍毹**……以故所撰传奇文词虽美而不风行于歌场，**反不若伶工所编之剧，转足以博人喝采也。故兹编于排场一事特详述之。**」

- **楔子自成一韵**：《窦娥冤》楔子真文／第一折尤侯；《金线池》楔子鱼模／第一折真文。**楔子的宫调恒为仙吕（与第一折同宫），但韵部另起，不与第一折连读；「四折四韵不重」不把楔子算进去。**
- **套内重韵是允许的**：「头」字在《窦娥冤》第一折押五次；「休」字在《救风尘》第二折押四次；「人」「门」在《救风尘》第三折各押三四次。→ 实证「**剧曲可重韵、清曲不可**」。
- **主唱权＝主角权**（《救风尘》）：当事人宋引章（外旦）全剧一支不唱，唱全给了「来解决问题的人」赵盼儿，剧名也随之定为《赵盼儿风月救风尘》——**结构、唱权、剧名三者是同一个决定**。
- **唱的人和推动的人可以分开**（《金线池》）：正旦 41/41 支，推动情节的却是不唱的石府尹（三次留场念下场诗、两次定计、末折假刑）。

### 10a 昆曲角色十五门表

**来源**：王季烈《螾庐曲谈》卷二第四章 4.7，扫描页 p0167（笔记 `wang-jilie-yinlu-qutan/02-juan2-zuoqu-b.md`）。

| 大类 | 细分 |
|---|---|
| 生 | 老生、冠生、小生 |
| 旦 | 老旦、正旦、刺杀旦、作旦、闺门旦、贴旦 |
| 净 | 正净、白净、副净 |
| 丑 | 丑（仅一门） |
| 其他 | 外、末 |

**配置律（原文）**：
> 「一部传奇中，**最好各门角色俱备，而又不宜重复**。惟欲角色全备犹易，欲不重复甚难。则于**剧中主要之人避去重复、配角不妨重复；然在一折内仍须避去重复也。**」

**与套数的匹配**（p0166，即 reference-taoshu.md §4e 末段）：诉情大套宜生旦；欢乐宜同唱；游览、行动亦多宜同唱；悲哀、幽怨多宜旦唱；**生净（大面）、老生遇哀剧以用北曲为宜**；**粗曲限于丑、净、白面、二面所唱**；净丑上场不用引子，用短曲（清单见 reference-taoshu.md §5b）。

### 10b 行当分化史与「均劳逸」

**来源**：吴梅《曲学通论》第六章「作法上」（己）均劳逸，扫描页 p0046–p0047（笔记 `wu-mei-quxue-tonglun/07-tonglun-zuofa-shang.md`）。**本章最独有的一条。**

- **分化史（原文）**：「传奇中脚色总言之曰生旦净丑。**自明中叶海盐派盛行，继之以昆腔，而脚色遂繁**——生有**老生、冠生、巾生、二生**之名；旦有**老旦、正旦、搽旦、小旦、贴旦**之名；净有**大、小、中**之区别，惟丑则一耳。统计十有三门，今人谓**十门脚色**，举其成数言之也。」
  > ⚠️ **吴梅作十三门、王季烈作十五门，两家门目不同（吴梅有巾生、二生、搽旦、小旦，无刺杀旦、作旦、闺门旦、外、末），并列不合并。**
- **昆腔以前一色到底**：「未有昆腔以前，每本传奇所用脚色大率以一人终始之，自开场至结尾无论多至数十折，总以一色任之，**从无有数人分任其劳者**。」
- **昆剧的折—行当配置法**：「昆剧既盛，角目之分析亦细，而每一部中所蓄伶人各色均不下七八人。故凡演一剧，先将剧中所定角目逐折细检：**同一生脚也，第几折宜用冠生，第几折宜用巾生；同一旦脚也，某几折宜用正旦，某几折宜用小旦**；各视曲中文字与字迹之何若，而后定为某脚某脚也。」
- **给填词者的硬规则与两条理由**：「填词者当知优伶之劳逸：**如上一折生为主角，则下一折再不可用生矣**，他角色亦然。此其故有二：一则优伶更番执役不致十分过劳；二则衣饰裙钗更换颇费时间——**前折下场与后折上场，为时不过三五分钟**，以极短极促之时间而更换最难穿戴之服饰，虽十手犹不能为也。」
- **点名的失败案例**：「文人填词能歌者已少，能知此理者非曾经串演不能，故尤少也。往读名家传奇，此失独多，**汤若士之《紫钗》、徐榆村之《镜光缘》更多是病，此所以不能通常开演也**。」

## §11 《桃花扇》凡例十六条原文 · 纲领四色四气三十人表

**来源**：维基文库《桃花扇凡例》《桃花扇纲领》（底本为康熙刊本系统），笔记 `kong-taohuashan/00-fanli-gangling.md`。原文未作删节与改写；笔记已由繁转简，「齣」统一作「出」。

### 11a 凡例十六条（原样转写）

1. 剧名《桃花扇》，则桃花扇譬则珠也，作《桃花扇》之笔譬则龙也。穿云入雾，或正或侧，而龙睛龙爪，总不离乎珠；观者当用巨眼。
2. 朝政得失，文人聚散，皆确考时地，全无假借。至于儿女钟情，宾客解嘲，虽稍有点染，亦非乌有子虚之比。
3. 排场有起伏转折，俱独辟境界；突如而来，倏然而去，令观者不能预拟其局面。**凡局面可拟者，即厌套也。**
4. 每出脉络联贯，**不可更移，不可减少**。非如旧剧，东拽西牵，便凑一出。
5. 各本填词，每一长折，例用十曲，短折例用八曲。优人删繁就减，只歌五六曲，往往去留弗当，辜作者之苦心。**今于长折，止填八曲，短折或六或四，不令再删故也。**
6. 曲名不取新奇，其套数皆时流谙习者；无烦探讨，入口成歌。**而词必新警，不袭人牙后一字。**
7. 词曲皆非浪填，**凡胸中情不可说，眼前景不能见者，则借词曲以咏之**。又一事再述，前已有说白者，此则以词曲代之。若应作说白者，但入词曲，听者不解，而前后间断矣。其已有说白者，又奚必重入词曲哉。
8. 制曲必有旨趣，**一首成一首之文章，一句成一句之文章**。列之案头，歌之场上，可感可兴，令人击节叹赏，所谓歌而善也。若勉强敷衍，全无意味，则唱者听者，皆苦事矣。
9. 词曲入宫调，叶平仄，**全以词意明亮为主**。每见南曲艰涩扭挪，令人不解，虽强合丝竹，止可作工尺字谱，何以谓之填词耶。
10. 词中所用典故，信手拈来，不露饾饤堆砌之痕。化腐为新，易板为活。点鬼垛尸，必不取也。
11. 说白则抑扬铿锵，语句整练，设科打诨，俱有别趣。**宁不通俗，不肯伤雅**，颇得风人之旨。
12. 旧本说白，止作三分，优人登场，自增七分；俗态恶谑，往往点金成铁，为文笔之累。**今说白详备，不容再添一字。**篇幅稍长者，职是故耳。
13. 设科之嬉笑怒骂，如白描人物，须眉毕现，引人入胜者，全借乎此。今俱细为界出，其面目精神，跳跃纸上，勃勃欲生，况加以优孟摹拟乎。
14. 脚色所以分别君子小人，**亦有时正色不足，借用丑净者**。洁面花面，若人之妍媸然，当赏识于牝牡骊黄之外耳。
15. **上下场诗，乃一韵之始终条理**，倘用旧句、俗句，草草塞责，全出削色矣。**时本多尚集唐，亦属滥套。今俱创为新诗**，起则有端，收则有绪，著往饰归之义，仿佛可追也。
16. 全本四十出，其**上本首试一出，末闰一出，下本首加一出，末续一出**，又全体四十出之始终条理也。有始有卒，气足神完，且脱去离合悲欢之熟径，谓之戏文，不亦可乎？
   （维基文库此条作「下本首下本首加一出」，「下本首」三字重出，系该页衍文；按文义与全剧实际体例校正为一次。）

**十六条按功能归类**（笔记为转 skill 所做的整理，不是原文分组）：

**孔尚任自释（原文）**：
> 色者，离合之象也。男有其俦，女有其伍，以左右别之，而两部之锱铢不爽。气者，兴亡之数也。君子为朋，小人为党，以奇偶计之，而两部之毫发无差。张道士，方外人也，总结兴亡之案。老赞礼，无名氏也，细参离合之场。明如鉴，平如衡，名曰传奇，实一阴一阳之为道矣。　　云亭山人偶定

**三条要点**：①分类轴不是善恶，是**功能**——「色」管离合线、「气」管兴亡线，两线各自左右／奇偶对称配平；②正色只有两人（侯、李），**间色＝推动离合的中介**（杨龙友、李贞丽），**合色＝艺人／书贾一类穿针引线者**，**润色＝只出场帮衬气氛的**；③**经部两人是框架人物，单列一部，说明它是编制而不是点缀**——张道士「总结兴亡之案」（续四十出《入道》），老赞礼「细参离合之场」（试一出／闰二十出／加二十一出／续四十出），且老赞礼在第三、三十二、三十八出以太常寺赞礼身份参与事件。

### 11c 附：《小识》的四级顶针链与《本末》的填词校验回路

- **《小识》（康熙戊子三月）**：「传奇者，传其事之奇焉者也，**事不奇则不传**。」四级顶针：
  > 「其不奇而奇者，**扇面之桃花**也；桃花者，**美人之血痕**也；血痕者，守贞待字，碎首淋漓**不肯辱于权奸**者也；权奸者，魏阉之馀孽也；馀孽者，进声色，罗货利，结党复仇，**隳三百年之帝基**者也。」
  收在物证上：「帝基不存，权奸安在？惟美人之血痕，扇面之桃花，啧啧在口，历历在目，此则事之不奇而奇，不必传而可传者也。」
- **「借离合之情，写兴亡之感」的出处辨正**：此句常被系在《小引》《小识》名下，**实际出处是试一出《先声》副末白**；《纲领》末段「色者，离合之象也……气者，兴亡之数也」是它的分类学版本。**引用时要标对出处。**
- **《本末》的填词工作法**：孔自承「予虽稍谙宫调，恐不谐于歌者之口」，得吴人王寿熙（时优熟解套数者）朝夕过从，「示予以曲本套数……遂依谱填之。**每一曲成，必按节而歌，稍有拗字，即为改制，故通本无聱牙之病。**」——**这是曲牌体填词的标准校验回路**，与凡例第 9 条互为表里。另：丙戌在恒山观演两日，「予意有未惬者，呼其部头，即席指点焉」（以排练指点方式二次修订）。
- **《砌末》一篇缺**：维基文库《桃花扇》条目前置篇目只有小引、小识、本末、凡例、考据、纲领、序七种，**没有《砌末》**；gushiwen、国学梦等通行电子本也只收正文四十四出。须查纸本校注本或康熙刊本影印件。**这是已知缺口，不要当作孔尚任没写。**
- **《考据》的五类材料**：①野史编年——无名氏《樵史》二十四段，唯一**按日系事**的一类，各出出目下标的「癸未三月」「甲申四月」等系年即由此而来；②当事人文集（侯朝宗《壮悔堂集》十三首等）；③时人诗文集中涉及剧中人的篇目（钱牧斋、吴骏公、杨龙友、冒辟疆、沈眉生、陈其年、龚孝升）；④**反面人物自作的戏**——《石巢传奇》二种（《十错认春灯谜》《燕子笺》），即阮大铖本人的剧本，用于第四出《侦戏》、第二十五出《选优》直接搬演；⑤逐条标出每条材料的篇数，**计数即证明「确考时地，全无假借」不是空话**。

## §15 体制演变表 · 杂剧 vs 传奇对照

### 15a 体制演变（吴梅《中国戏曲概论》）

**来源**：吴梅《中国戏曲概论》，底本 `_text/wu-mei-xiqu-gailun.ocr.txt`（吉林人民版合集），**引文一律标 `[待核]`**（网上未找到本书全文，笔记的待核标记全部保留）；笔记 `wu-mei-xiqu-gailun/01`、`02`、`03`。

**（一）诸宫调给了什么（卷上 p0281–p0283）**

| 项 | 内容 |
|---|---|
| 名字即结构法 | 「宋人所用大曲转踏，不过用一牌回环作之……惟此编每宫调中多或十余曲，少或一二曲，即易他宫调。**合若干宫调以咏一事，故谓之诸宫调。**」→ 转踏＝一牌反复；诸宫调＝多宫调连缀，**「换宫调」就是换段落、换情绪** |
| 样本 | 董西厢八支曲（〔黄钟出队子〕〔尾〕〔仙吕点绛唇缠令〕〔瑞莲儿〕〔风吹荷叶〕〔尾〕〔仙吕赏花时〕〔尾〕）「**已易三宫调**，全书体例皆如是」 |
| 三条硬特征（引施国祁） | **无出名关目**、**率填乐府方言不采类书故实**、**曲多白少**；不注工尺，是流传读本 |
| 长度差 | 「**诸宫调虽短，词牌则全；元剧虽长，而每牌止有其半。**」元剧套数多至十七八支，每支只用上叠、后叠换头不用——**长套靠「多支半牌」堆出来，不是靠「少支整牌」** |
| 一条反通说 | 「是北曲之不能完备，**不在明嘉隆昆腔盛行以后，反在元人继述之不周**。」 |

**（二）杂剧体格：与诸宫调的四条对照（卷上 p0288）**

| # | 诸宫调 | 杂剧 |
|---|---|---|
| 1 | 不分出目 | **通例四折**；例外：纪君祥《赵氏孤儿》五折、张时起《花月秋千记》六折，「顾不多见也」 |
| 2 | 不分角目，总以一人弹唱（「与后世评话略同」） | 分末、旦、外、丑诸目，**以末、旦为主**，元人所谓「旦、末双全」 |
| 3 | 无动作状态 | 「**记动作者曰科，记言语者曰白，记歌唱者曰曲**」，「是合歌舞言动而一之也，**是剧曲之进境也**」 |
| 4 | （体格之外）文字 | 「至论文字，**则止有本色一家**，无所谓词藻缤纷纂组繁密也」 |
| 5（另段） | — | 「江西嘌唱，尤能变易故常，**别创南北合套之格**。繁声一启，词法大备。」——**南北合套是元代由民间清唱班社（不是文人）创出的格** |

> **口径提示**：「四折」吴梅说的是**通例而非铁律**，且自己就举了五折、六折两个反例。**杂剧四折一楔子的松动不是明人才开始的，元人已有。**

**（三）明杂剧破元剧的四条（卷中 p0301–p0302）——一张交换表**

| # | 元剧 | 明剧 | 吴梅举的例 |
|---|---|---|---|
| 1 | 多四折 | **不拘** | 徐渭《四声猿》、沈自晋《秋风三叠》＝每种一折；王衡《郁轮袍》、孟称舜《桃花人面》＝多至七折、五折。→「**是折数不定也**」 |
| 2 | 多一人独唱 | **不守此例** | 《花舫缘》第三折是旦唱；《春波影》第二折杨夫人唱、第四折老尼唱。→「**是唱角亦不定也**」 |
| 3 | 多用北词 | **尽多南曲** | 汪道昆《高唐梦》、来集之《挑灯剧》。→「**是南北词亦可通用也**」 |
| 4 | 文字拙朴；**排场至劣** | 文字研丽；**排场有次第** | 「元剧排场至劣，明则有次第矣」 |

> **代价（原文）**：「然而**苍莽雄岩之气，则明人远不及元**，此亦文学上自然之趋向也。」→ **四条松动是一整套交易，不是可以只挑一条来松。**
> 另一件破格事件（p0304）：**徐渭《女状元》「独以南词作剧，破杂剧定格，自是以后南剧擘乳矣」**——南杂剧的起点被系在这一部上。

**（四）声腔三变（卷中 p0297–p0298，原样转写）**

| 时 | 内容 |
|---|---|
| 第一时 | 开国之初半沿元季余习，「其后南剧日盛，家伶点拍，事竞增华，作家辈出，一洗古卤元刺之风。于是海内向风，遂得与古法部相颉颃。」 |
| 第二时 | **海盐调**。澉川杨梓元时得贯云石之传，长子国材「遂得南声之秘奥，**别创新声，号为海盐调**，西江两京间翕然和之」。 |
| 第三时 | **昆腔水磨调**。「嘉隆间，太仓魏良辅、昆山梁辰鱼，以善讴名天下。**良辅探讨声韵，坐卧一小楼者几二十年，考订《琵琶》板式，造水磨调。辰鱼作《浣纱记》付之**，流丽稳协，远出弋阳、海盐旧调之上。」 |

> 两个对编剧有用的事实：①水磨调是**在《琵琶记》的板式上订出来的**，《琵琶记》因此成了昆曲板式的「母本」；②**新腔要靠一部配套的新戏才能立住**（良辅造腔、辰鱼作《浣纱》付之）。**腔与本是一起出来的。**

**（五）明人传奇作家流别四端（卷中 p0308，原样转写）**
> 「若夫作家流别，约分四端。自《琵琶》、《拜月》出，**而作者多喜拙素**。自《香囊》、《连环》出，**而作者乃尚词藻**。自玉茗『四梦』**以北词之法作南词**，而俪越规矩者多。自词隐诸传，**以俚俗之语求合律**，而打油钉铰者众。于是**矫拙素之弊者用绮语，革辞采之繁者尚本色**。**正玉茗之律，而复工于琢词者，吴石渠、孟子塞是也；守吴江之法，而复出以都雅者，王伯良、范香令是也。**」

**（六）清胜明的五端与出数的改良（卷下 p0323）**
1. **剧场旧格之改良**：「**明代传奇，率以四十出为度，少者亦三十出，拖沓泛滥，颇多疵病**……又事实离奇，至山穷水尽处，辄假神仙鬼怪，以为生旦团圆之地。**清人则取裁说部，不事臆造，详略繁简，动合机宜，长剧无穴费之辞，短剧乏局促之弊。**又如《拈花笑》《浮西施》等，**以一折尽一事，俾便观场，不生厌倦**。杨笠湖之《吟风阁》，荆石山民之《红楼梦》，**分演固佳，合唱亦善**。」
2. **曲谱**：明无佳谱（《太和正音》正衬未明，沈璟《南谱》搜集未遍）→ 清有《南词定律》「板式可遵矣」、《九宫大成谱》「订谱亦有依据矣」。
3. **曲韵**：《中原音韵》只分平声阴阳 → 清沈乘麐《韵学骊珠（辑要）》已及去声，周昂《中州》又分两上，「有**随调选字**之妙」。
4. **论律之书**：明仅王骥德、魏良辅 → 清有毛奇龄《竟山乐录》、陈澧《声律通考》、凌廷堪《燕乐考原》、戴长庚《律话》。
5. **目录与歌谱**：黄文旸《曲海》、《曲海总目提要》；叶堂《纳书楹》、冯起凤《吟香堂》。
> 总结句：「**总核名实，可迈前贤，惟作者无多，未免见绌。**」即**清代的工具比明代好，作品比明代少**。
> 断代总纲（p0343）：「余尝谓**乾隆以上，有戏有曲；嘉道之际，有曲无戏；咸同以后，实无戏无曲矣**。」——**「戏」（排场／关目）与「曲」（文辞／音律）是两样东西，可以各自存亡。**

**（七）传奇鼻祖与名义区分（王季烈《螾庐曲谈》卷四，p0314–p0320）**

| 条 | 原文 |
|---|---|
| 代言体是分界线 | 「**元杂剧之曲文宾白皆是剧中人口气，而非作剧者之口气；董西厢则通体系作剧者记事之文，而不作代言体。然则世称董西厢为元明传奇之鼻祖，实则体裁各别，未可牵混也。**」（p0314） |
| 元杂剧体裁的两项转变 | 「**由叙事体而变为代言体；由有换头之全阕曲词而变为不用换头之单支曲词**」（p0316） |
| 名义区分 | 「**以四折为一本者名曰杂剧；用明人体裁一本多至数十折者名曰传奇。又传奇杂剧之总称亦曰传奇——此为明代以来所通行之区别也。**」（p0320） |
| 传奇鼻祖的裁定 | 王实夫《西厢》「其实乃叠杂剧五本而成，其末一本为关汉卿所续」；《荆钗》为明宁献王所撰；《杀狗》《白兔》「当是后人伪托」；《幽闺》「所用曲牌类多生僻，非后人所习用」。「**故传奇鼻祖当推《琵琶记》**……则谓传奇实始于明初无不可也。」（p0320） |

### 15b 杂剧 vs 传奇对照（25 行；关汉卿三剧实证 vs 牡丹亭／桃花扇实证）

**来源**：`guan-jiufengchen/01` 第 6 节、`02` 第 6 节、`03` 第 6.1 节三张表合并去重；传奇一侧的实证出自 `tang-mudanting/`、`kong-taohuashan/`。

| # | 项 | 元杂剧（关汉卿三剧实证） | 明清传奇（《牡丹亭》《桃花扇》《长生殿》实证） |
|---|---|---|---|
| 1 | 结构单位 | 四折一楔子，楔子可无（《救风尘》即无） | 数十出；《牡丹亭》55 出、《桃花扇》44 出＋4 个非编号出、《长生殿》50 折 |
| 2 | 篇幅 | 《窦娥冤》41 支曲、曲文 2,695 字；《救风尘》44 支；《金线池》41 支 | 《牡丹亭》425 条唱段、《桃花扇》250 条唱段 |
| 3 | 演出时长 | 一昼夜可演完 | 《桃花扇》须上下本各演一夜 |
| 4 | 谁唱 | **一人主唱**，三剧四折共 123 支全归正旦，无一例外 | 各行分唱，可对唱、可合唱带合头 |
| 5 | 主唱与主角 | **主唱权＝主角权**，且排他（《救风尘》当事人宋引章一支不唱） | 生旦均可唱，主次靠戏份不靠唱权；北曲套才一人主唱到底（《牡丹亭·虏谍·冥判·硬拷》） |
| 6 | 唱者与推动者 | 可以分开（《金线池》正旦唱满，推动的是不唱的石府尹） | 谁推动谁就唱（《桃花扇》副末既开场又入戏当剧中人） |
| 7 | 宫调 | **一折一宫调，四折四宫调不重**，宫调名白纸黑字写在首曲前 | 一出可换宫、可南北合套；且《牡丹亭》《桃花扇》**电子本都不标宫调**，宫调只能当例证不能当依据 |
| 8 | 宫调的位置 | **第一折恒仙吕、第四折恒双调**（三剧三中） | 无此律；《长生殿》的律是「前一折与后一折宫调不重复」 |
| 9 | 套数 | 有定式，首尾数曲一定、中间可增删倒置（十二折十一合体式） | 南曲只定「引子在出场、尾声在归结」，中间靠慢／中／急排序 |
| 10 | 韵 | **一折一韵到底，四折四韵不重**；楔子自成一韵 | 一出可换韵（随移宫）；玉茗四梦平上去韵间杂入声被判「不足为法」 |
| 11 | 套内重韵 | **允许**（「头」字一折押五次） | 允许（吴梅：古剧皆然，「避而牵强，不若重而稳协」）；**清曲则不许** |
| 12 | 同牌重出 | 北曲曰**幺篇**；三剧共 5 支，**无一处「前腔」「换头」** | 南曲曰**前腔／换头**，两部传奇每出皆见 |
| 13 | 开场 | 无副末开场，剧中人上场诗自报家门直接开戏 | 副末开场；《桃花扇》把它扩成贯穿线（试一出／闰二十出／加二十一出／续四十出） |
| 14 | 收场 | 全剧末**题目正名**二句或四句，念不唱 | 每出末**下场诗**；《牡丹亭》55 出集唐下场诗全备；《桃花扇》凡例 15 反集唐、俱创新诗 |
| 15 | 曲白比 | 《窦娥冤》1:3.1、《救风尘》1:1.8、《金线池》1:1.7；单折可低至 1:0.7、高至 1:18.4 | 以曲为主；李渔专立「宾白第四」正因为传奇的宾白弱 |
| 16 | 净丑 | 有科诨（丑扮小闲、店小二），**但一支曲也不唱**（《救风尘》） | 净丑有专属曲牌（粗曲、短曲），可唱可念；净丑上场不用引子 |
| 17 | 尾声 | 四折多有；**末折可省，条件是收束已由官断＋〔词云〕接过去**（《金线池》） | 每出有尾声或可省的条件（同牌四支＋换头并用、叠用曲牌、短折） |
| 18 | 楔子／过场 | 楔子仙吕一至二支，自成一宫一韵 | 无楔子；过场用短曲急曲、粗曲（「非此则情节不贯、线索不联」） |
| 19 | 收煞 | 官断＋〔词云〕韵语；《窦娥冤》团圆但主角已死（鬼魂受祭） | 大收煞；《牡丹亭·圆驾》团圆、《桃花扇》破团圆（吴梅赞，骂《南桃花扇》「更属无谓」） |
| 20 | 南北曲比例 | 纯用北词 | **南曲十之八九、北曲十之一二**（王季烈 p0161） |
| 21 | 北曲的用途 | 全剧 | 给雄壮、悲愤、激昂、健捷；生净与老生的悲剧用北曲 |
| 22 | 宾白的地位 | 「宾白仅供点清眉目之用，似乎不必求工」（元剧演法：歌者自歌、白者自白） | 必须求工（三条理由见吴梅《曲学通论》六·3.2）；孔尚任「说白详备，不容再添一字」 |
| 23 | 排场 | 「**元剧排场皆呆板且拙率**」（王季烈 p0179）；虚写实演每欠斟酌 | 「排场之周匝、关目之细密，则后人实胜于前人，至国朝康乾之际而为最善」 |
| 24 | 文辞 | 「曲文之朴茂本色，明人不如元人、国朝不逮明人」 | 同左（王季烈总判，p0180） |
| 25 | 角色数 | 末、旦、外、丑，「旦末双全」 | 昆曲十五门（见 §10a）；《桃花扇》纲领编制三十人 |

## §16 三分工（制曲／谱曲／度曲）与「曲谱 vs 宫谱」辨析 · 该读哪些本子、查哪几部谱

### 16a 三分工

**来源**：王季烈《螾庐曲谈》卷一第一章绪论，扫描页 p0033–p0034（笔记 `wang-jilie-yinlu-qutan/01-juan1-duqu.md`）。

> 「顾此四端、一人之精力未必悉能精究，则不妨**分途程功**：**长于文藻者任制曲之事，精于音律者任谱曲之事，耳听口敏嗓亮者任度曲之事**。合此三种人才精心研究，始得尽昆曲之能事也。」

| 分工 | 做什么 | 在《螾庐曲谈》的哪一卷 |
|---|---|---|
| **制曲** | 填词——按曲牌格律填写曲文，**编剧做的事** | 卷二《论作曲》 |
| **谱曲** | 订宫谱、点板注工尺 | 卷三《论谱曲》 |
| **度曲** | 演唱 | 卷一《论度曲》 |

**两种次第：造出来的顺序 ≠ 学会的顺序（p0034，全书纲领）**
> 「论**构成**昆曲之次第，则先填词、次制谱、而后度曲；然论**习**昆曲之次第，则须先习度曲、而后学填词制谱。盖**不习度曲，则曲牌之选择、衬字之安放、四声之布置，决不能得其宜——纵使文词极佳，而不能被之管弦。**故余之谈曲，先度曲、次制曲、次谱曲，终乃论其源流沿革焉。」
→ **选牌、放衬、布四声三件事在动笔之前就被唱法决定。**

**一条尖锐的判断（卷一 p0042）**：「今之习昆曲者大都仅以伶工笛人为师，**若辈识字无多、文义有限**……**至于四声阴阳音韵本非彼之所知，如何望其教人？此事学者宜另于书籍中求之**——如周德清《中原音韵》、范善溱《中州全韵》、王鵕《音韵辑要》。」

**制谱四步（卷三 p0212）**：「一曰**点正板式**；二曰**辨别四声阴阳**；三曰**认明主腔**；四曰**联络工尺**。」并「**板疏则工尺宜简、板密则工尺宜繁；不先定板式，无从定腔格也。**」
**主腔说（卷三第四章 p0245）**：「**凡某曲牌之某句某字有某种一定之腔，是为某曲牌之主腔。**」其后 p0246–p0300 是一份极长的主腔索引表（逐宫调、逐曲牌列「某牌某句→见某折」），**是谱曲者的查表，不进 skill**。但它证明一条：**曲牌的「声情个性」固化在几个主腔上**，所以换曲牌＝换主腔＝换情绪色彩；**集曲之所以必须「首数句取正曲之首数句、末数句取正曲之末数句」，正是因为主腔多在句首句末——次序一乱，主腔就散了。**

**同一曲牌、不同的词，宫谱必定不同（卷三 p0239）**：「**同一曲牌之曲而宫谱彼此歧异、不能一致者，因其曲中各字之四声阴阳彼此不同故也。**」→ **曲牌体「填词」不是往固定旋律里塞字，而是往固定的板式与腔格框架里放四声。**（同治末年俞曲园、光绪张文襄等人「规仿弹词，令伶人强以弹词之宫谱歌之」，王季烈判为「**文人不谙音律，好为武断**」。）

**明清传奇的同一条工作流另有一手记载**（王季烈卷四 p0345，记袁令昭）：「**令昭则栏园弟子也，花晨月夕征歌按拍，一词脱稿即令伶人习之，刻日呈技**」——与孔尚任「每一曲成，必按节而歌，稍有拗字，即为改制」、翁偶虹「改词—编腔—请王瑶卿审腔」的板腔体工作流平行。

### 16b 「曲谱」与「宫谱」的辨析

**来源**：王季烈《螾庐曲谈》卷三第一章开宗第一句，扫描页 p0209。

> 「**厘正句读、分别正衬、附点板式，示作曲家以准绳者，谓之『曲谱』；分别四声阴阳、腔格高低、旁注工尺板眼，使度曲家奉为圭臬者，谓之『宫谱』。**」

| | 曲谱 | 宫谱 |
|---|---|---|
| 是什么 | **填词的格律书** | **演唱的乐谱** |
| 给谁用 | 编剧（制曲者） | 演员／笛师（度曲者） |
| 有哪些 | 《钦定曲谱》《南词定律》《北词广正谱》 | 《九宫大成》《纳书楹》《吟香堂》《集成曲谱》 |

王季烈自承习俗混用（p0210）：「**曲谱名之不正已非一日，本书亦以宫谱而袭曲谱之名，盖从宜从俗，不遑订正耳。**」
→ **回答「昆曲的格律去哪里查」时，必须先问对方要的是填词格律（曲谱）还是唱腔乐谱（宫谱）——两者都叫「曲谱」，混了就会给错书。**

### 16c 该查哪几部谱

**来源**：王季烈卷二第一章 1.4（p0119）、2.6–2.8（p0137–p0140）；卷三 2.4（p0213）。

| 书 | 王季烈的判断 |
|---|---|
| **《钦定曲谱》** | **实用首选**：有石印本易购；北曲采自明《啸馀谱》，南曲采自沈璟《南曲谱》；「每字旁注四声，并点板式、正衬、句读、押韵之处，一一注明。**固作曲者不可不备之书也。**」**但北曲不点板**，另有五病（见下） |
| **《北词广正谱》**（李元玉） | 北曲最精审；注明「上去不可移易」之处，**是查务头的依据**；「流传甚少、购求不易」 |
| **《南词定律》**（吕士雄等） | 南曲最精审、**板式最详**；同样难得 |
| **《九宫大成南北词宫谱》** | 最完备，「**然过于繁复，初学读之转无所适从；且依十二月分列宫调，自我作古，徒滋后人之惑**」 |
| **《吟香堂》《纳书楹》** | 旧曲宫谱中**板式正确者**（与《集成曲谱》并列） |
| 俗伶传抄之宫谱 | 「**正赠不别且多抽板以图省事，断不足据也。**」 |

**吴梅的取舍（两家并列）**：北曲**只认《九宫大成》**——「《啸馀谱》之北曲谱则**断断不可从**也」（《顾曲麈谈》北曲作法 p0208）；《麈谈》举南曲旧谱为「沈宁庵《南九宫谱》、**钮少雅之《南曲范》**」，《通论》举沈自晋《南词新谱》，**两书举的谱不同**；选《南词定律》的理由是「考订最精，**且系殿板，购求尚易**」（笔记 `10-guqu-nanqu-zuofa.md` 第 0 节）。

**《钦定曲谱》五病（王季烈 p0137–p0139，编号原样）**
1. **北曲衬字未经标出，混作正字者甚多**（如黄钟宫〈古水仙子〉第四句至末句之叠韵字皆系衬字未标；正宫〈笑和尚〉各句首之「吉丁丁当」等字亦然）；
2. **脱字脱句甚多**（北仙吕〈赏花时〉首脱「百尺鳌山簇翠烟、万丈虹光散锦」二句；北南吕〈梁州第七〉脱「碧云轩」二句等）；
3. **收别体而失载通行之格**（如南越调〈山麻秸〉收仙吕入双调之豆叶黄、正格反失）；
4. **一曲之末误联他曲**（如北南吕〈玉交枝〉之赤紧以下八句、北双调〈神缠曲〉之我怎生以下二十句、南正宫〈满江红〉急诸曲）；
5. **绝不相同之曲，因牌名相同误作一调**（如南越调〈山麻秸〉与仙吕入双调之豆叶黄、正宫之白鹤子与大石之好观音等）。
> 「凡此数端，举其大概而已。学者就《北词广正谱》《南词定律》《大成宫谱》诸书参互校勘，则可详知其是非得失矣。」

**版本：正衬分不分明决定能不能照填（p0140）**：旧刻本多不分正衬，或虽分而错误；曲牌好标别名、错讹尤多（梁州序、泣颜回误作好事近；雁儿落带得胜令只标雁儿落；沽美酒带太平令只标沽美酒）。**董氏（武进）刻本号为精美，然古人误处未能校正**；贵溪刘氏所刊大都谨守古人绳墨；**秣陵书局校对精审、正衬分明，实在董氏诸刻之上**；涵芬楼排印本「均细加校勘、订正曲牌、分别正衬，**填词者可以取则**」。

### 16d 该读哪些本子

**来源**：王季烈卷二第一章 1.3，扫描页 p0118。**这是全书最集中的一次历代传奇评断，原样转写。**

| 作品 | 王季烈的评断 |
|---|---|
| 元人百种 | 北曲之佳者，宫调无不合律、词采无不超妙；**然宾白失之率直、排场尤欠考究** |
| 《琵琶记》 | 曲文颇佳且合律，**然吃糠、剪发等折屡屡移宫换韵、未足为法** |
| 《荆钗记》 | 能合律而曲文平庸 |
| 《幽闺记》 | 亦有佳句，**然所用曲牌多生僻** |
| 《白兔》《杀狗》 | 虽负盛名而文字总劣，不堪寓目 |
| 玉茗四梦（汤显祖） | 文藻为有明传奇之冠，**而失宫犯调不一而足；宾白漏略、排场尤欠斟酌** |
| 《浣纱》《明珠》《玉玦》《红梨》 | **曲白并美，在明传奇中为最善** |
| 《燕子笺》《春灯谜》 | 排场特妙、词亦新颖，惟稍嫌尖刻（叶怀庭讥为「开笠翁恶札之端」） |
| 笠翁十种（李渔） | **构思巧妙，以供优孟衣冠，颇足动人，是其所长** |
| 《桃花扇》 | **宾白最工整、曲词亦佳；特平仄多失调、衬字欠妥贴，是其所短** |
| 吴石渠（吴炳）诸作 | 文采秾郁 |
| 蒋心馀九种 | 学玉茗而于曲律比玉茗考究，皆佳作 |
| **《长生殿》** | 「**词采、结构、排场并胜，而又宫调合律、宾白工整，众美悉具，一无可议者**」 |

**学曲次第（原文）**：「故学作曲者宜**先读《长生殿》**，次读元人百种、玉茗四梦、琵琶、幽闺、浣纱、明珠、玉玦、红梨、燕子笺、春灯谜、桃花扇、石渠五种、笠翁十种、藏园九种，**学其所长、去其所短**，则于作曲之道，思过半矣。」

**吴梅的两条并列意见**：①「学玉茗者，**须多读元曲，不可单读『四梦』**，所谓取法乎上，仅得乎中者也」（《中国戏曲概论》p0265 `[待核]`）；②读四梦「**但当学其文，不可效其法**」（《顾曲麈谈》南曲作法 p0188）。
**吴梅给的流派谱系（p0265–p0266 `[待核]`）**：玉茗（汤显祖）→ 粲花（吴炳，蕴藉）／百子（孟称舜一路，尖颖）→ 藏园（蒋士铨）→ 倚晴（黄燮清）→ 坦园（杨恩寿）。**距源愈远愈弱**，是他排座次的隐含规则。

**雅俗的界（王季烈 p0117）**：
> 「诗词皆宜于雅、而曲则有宜俗之处、有宜雅之处。**雅非一味典雅、而须出以超妙之笔；俗非一味俚俗、而须含有隽永之旨。**故堆砌典故、毫无机趣、与夫出词鄙俚、有伤大雅，皆非作曲所宜也。」
**本色论（王季烈 p0187）**：「**汉宫秋乃元帝昭君之口吻，故用妍丽之词；陈抟高卧乃隐士之口吻，故用超逸之语；屠户口吻故绝不作才语。然则不作才语处固是本色，即作才语处仍是本色也。**」——本色＝贴合说话人身份，**不等于一味俚俗**。
**判断一个曲牌体剧本是不是「戏」（王季烈卷四 p0314）**：曲文与宾白是不是剧中人的口气。**作者口气的叙事文不是戏，是说唱。**
