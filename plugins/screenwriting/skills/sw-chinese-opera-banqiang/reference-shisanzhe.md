# 十三辙逐字表（最小可用版）

> 用途：写唱词时把下句落字抄成一列，**逐字对照本表**判辙，不凭语感（SKILL.md 第十五节第 8 条）。辙名、旧十三辙与北方语音的三处不同、入声与上口字，见 [reference.md](reference.md) §3；本表只解决"这个字归哪个辙、是平是仄"。**本表不出自本批 25 本书**，来源与做法如下，每一步可核；它是最小可用版，不是韵书。

## 来源与做法

1. **音节归部**：搜狐"京剧十三辙的 402 个音节表"（盛世梨园，2019-12-06，注"转自京剧连载"）——13 辙 402 个音节，每音节一个例字。原页四处笔误已订正：姑苏辙 `bu` 重出（应为 `du`）、油求辙 `mou` 重出、言前辙 `uan` 应为 `ruan`、中东辙 `chang` 应为 `cheng`。该表按普通话韵母归部，即"新十三辙"。
2. **字**：本批 24 种源书全文（OCR 文本，含五种剧本与曲谱）里出现 8 次以上的汉字，按普通话读音（pypinyin 0.55）的韵母归到上表的辙，按语料频次排序，每辙取平声、仄声各前 42 字；繁体字剔除；轻声字（的、了、着、呢）不列。**排在前面的是语料里最常见的字，不是最适合作韵脚的字**。
3. **平仄**：按普通话四声，阴平阳平＝平、上去＝仄。**下句落平声、上句落仄声**的规则见 SKILL.md 6a。古入声字已派入四声；京剧仍按上口字读的六个字（学、约、却、北、贼、黑）标 △——§3.2 第 2 条只说京剧"不派入"，原书未说它们归何辙，本表照普通话位置放、只加标记。
4. **京剧例外叠加**（reference.md §3.2）：①**庚青**（-eng／-ing）在京剧旧十三辙归**人辰**（恒读 hén、成读 chén、生读 shén、兵读 bīn），按普通话新十三辙归**中东**——本表把它**单列一行**，两边都不混入；写戏时择一，全剧一致，并在唱段表标明用的是旧辙还是新辙。②**居鱼**（zhu、chu、shu、ru 一组）旧读归**一七**（珠、书、如按原韵并入衣期），新辙归姑苏——同样单列一行。
5. **双辙**：只标**白话常用的第二读音落在别的辙**的字（得 de／děi、谁 shuí／shéi、血 xuè／xiě、说 shuō／shuì……），字典式的全部读音不标。同一字两个读音同辙（长 cháng／zhǎng）不标。

## 最易混的两组

1. **-ei／-ui 归灰堆，不归一七（衣期）**：碑、悲、杯、辈、泪、贵、内、类、水、谁、回、非、飞、追、归、堆、灰、雷、美、味、位、备、配、退、罪、岁、醉。一七只收 -i、-ü、-er 和 zhi／chi／shi／ri／zi／ci／si。对照实验里一段衣期辙唱段的末句兼重点句落在"碑"字上，整段的韵就是被这一个字定错的，而诊断清单凭语感判了"过"。
2. **-eng／-ing（庚青）**：旧十三辙归人辰、新辙归中东，见上表单列行。不管选哪一边，**同一出戏里不能一段按旧、一段按新**。

## 怎么用（自检动作）

- 写完一段唱：下句落字抄成一列 → 每个字在本表找到行 → 行名全同才算一辙到底；有一个不同就是出辙，**末句、重点句出辙比中间出辙更伤**，因为它是全段的收口。
- 落字在"仄声"格而它是下句：换字，或确认这一段是有意用仄声韵（见 6a 的例外）。
- 落字带"双辙"：写明按哪个读音唱，交琴师与演员。
- 落字不在表里：本表只收语料高频字，不在表里不等于不押；按韵母查第二列"韵母"栏归部，再按普通话声调定平仄。
- 用豫剧、川剧、越剧：本表不适用（三张韵表互不通用，SKILL.md 6d），见 [reference-yuju-difang.md](reference-yuju-difang.md) §4、§7。

> 材料缺口：①本表是普通话韵母的机械归部加京剧三处例外，**没有任何一本韵书作书证**；②居鱼组、庚青组、入声六字的"京剧归何辙"只到 liu/04 p0169–0171 说到的程度；③字来自理论书与剧本混合语料，韵脚适合度未经人工筛选。
