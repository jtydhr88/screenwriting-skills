# 戏曲编剧·板腔体（Chinese Opera Playwriting: the Banqiang System）

> **输出语言＝提问语言**；术语一律锚回原词，见 [sw-workflow/terms.md](../sw-workflow/terms.md)，不自创译名。戏曲术语（板腔体、曲牌体、韵辙、板式、行当、程式、宾白、科介）没有英文对应物，任何语言下保留原词加一句释义。

本 skill 是这套 skill **舞台层**里戏曲的**板腔体**一格。它现在只装了陆军的唱词方法（从 `sw-dialogue` 搬来，那里不该有它），再加一张媒介边界表。板式、剧种韵辙、跨剧种的结构方法与大师语料还没进来，缺口在第一节列得很清楚——**description 只承诺已有的部分**，缺的不会因为写在这里就被触发。

唱词范例见 [reference.md](reference.md)。

---

## 〇之一、为什么按声腔体系分，不按剧种分

戏曲不是一个门类，是两套写法：

| | **曲牌体**（元杂剧、明清传奇、昆曲；川剧高腔） | **板腔体**（京剧、豫剧、越剧、秦腔、评剧、沪剧；粤剧的梆黄） |
|---|---|---|
| 结构单位 | 杂剧**四折一楔子**；传奇数十**出** | **场** |
| 谁唱 | 杂剧**一人主唱**，一折从头到尾只有正末或正旦唱 | 行当分唱，谁都可以唱 |
| 唱词怎么写 | **填词**：每支曲牌有固定字数、句式、平仄，词填进去；一折一宫调，曲牌联套 | **上下句**：七字或十字的上下句为基础，靠板式变化撑起唱段，句数不定 |
| 编剧要懂的 | 曲牌格律、宫调、南北曲 | 板式与情绪的对应、韵辙 |

结构单位和唱词写法两项都不同，所以是两个 skill。**曲牌体另开 `sw-chinese-opera-qupai`**（尚未建，见第一节）。

**剧种不是分 skill 的轴。** 京剧、豫剧、越剧之间的差别是查哪张韵表（十三辙 vs 中州韵）、哪张板式表（西皮二黄 vs 梆子的慢板／二八板／流水板／飞板）——同一方法配不同的表，是 reference 附录，不是 skill。中国三百多个剧种，一剧种一 skill 是组合爆炸。

**两个不干净的边**：**粤剧**梆黄是板腔、小曲是填词，两套混用，而且用粤语，九声与韵部和普通话完全不同——它要不要单开，看模型的粤语音韵够不够用来查表，材料进来再测；**川剧**昆、高、胡、弹、灯五腔并用，高腔属曲牌体，它会同时出现在两个 skill 的附录里。

## 〇之二、媒介边界：通用层哪些能用在戏曲上，哪些不能

戏曲项目照样先走 `sw-workflow`，但通用 skill 进来之前要按这张表取舍：

| 通用 skill 的哪一层 | 能不能用在板腔体戏曲上 |
|---|---|
| `sw-story-structure` 第六节：**起承转合、八种开头、找核＋加减乘除、高潮四病、结尾八法、变化要多** | **能，而且是首选**。陆军这一节本来就是从小戏与戏曲经验里写出来的，例证多半是戏曲（《包公赔情》《阿二接妻》《打铜锣》） |
| `sw-story-structure` 的 BS2 十五节拍、演示板 40 卡、页码表 | **不能**。页码锚点是 110 页电影的产物；戏曲按场与唱段切分，不按页 |
| `sw-premise-theme`：前提、主控思想、戏核 | **能**，直接可用。「戏核要好」本来就是陆军提法 |
| `sw-character-conflict`：三维人物、对立统一、对手 | **能**，但**行当**（生旦净丑）会先于三维决定一个角色怎么写，这一层本 skill 尚未收录，见第一节缺口 |
| `sw-dialogue` 第六节：**语言要美、典雅美／本色美、对话三要求** | **能**，用于**宾白**。「戏曲唱词的本色美应更胜于典雅美」那句就是为戏曲写的 |
| `sw-dialogue` 的美式禁忌（不用括注、不写小对话、遮名可辨） | **部分能**。遮名可辨对唱词同样成立；「不用括注」不适用，戏曲本子里的科介是正文 |
| `sw-scene-craft`：进出、价值转折、道具 | **能**，但**晚进早出不适用**——戏曲的自报家门、定场诗是程式，不是可删的铺垫 |
| `sw-format-adaptation` 的三种体例（spec／场号制／柱・ト書き） | **不能**。戏曲剧本体例（唱／白／科介的排法、板式标记）本 skill 尚未收录 |
| 剧集层七个 skill | **不能**。戏曲连台本戏与剧集的「引擎」是两回事，不要套 |

**一句话**：陆军能用，页码不能用，程式不是铺垫。

## 一、本 skill 的覆盖范围与缺口

**已有**（第二节，来源陆军《编剧理论与技法》）：唱词的选韵、句式、布局三条规则，配 reference 里六组范例。陆军的例子全是越剧、沪剧和小戏，都是板腔体，所以这部分归本 skill。

**板腔体的缺口**（按补入顺序）：

1. **跨剧种的结构方法**：一人一事、场的单位、行当决定写法、程式（自报家门、定场诗、下场诗、背供）、唱念做打的分配。来源：范钧宏《戏曲编剧技巧浅论》《戏曲编剧论集》、翁偶虹《翁偶虹编剧生涯》《翁偶虹戏曲论文集》、汪曾祺《汪曾祺谈戏》、张庚／郭汉城《中国戏曲通论》、王安祈、罗怀臻。
2. **剧种附录**（放 reference，一剧种一节，是表格不是方法论）：京剧十三辙与西皮二黄各板式（导板／慢板／原板／快板／散板）要几字句、配什么情绪（刘吉典《京剧音乐概论》）；豫剧中州韵与慢板／二八板／流水板／飞板；越剧、秦腔、评剧另议；粤剧待测。
3. **剧本体例**：唱／白／科介如何排、板式怎么标。
4. **大师语料**（对标 `chekhov-dramaturgy` 的做法，全本逐场拆）：翁偶虹《锁麟囊》、陈亚先《曹操与杨修》、杨兰春《朝阳沟》、田汉《白蛇传》《谢瑶环》、汪曾祺等《沙家浜》、徐进越剧《红楼梦》、魏明伦《潘金莲》《巴山秀才》。

**曲牌体是另一个 skill**（`sw-chinese-opera-qupai`，尚未建）：填词法、宫调与套数、一人主唱的结构，来源李渔《闲情偶寄》词曲部、吴梅《顾曲麈谈》《曲学通论》、王季烈《螾庐曲谈》；全本关汉卿《窦娥冤》《救风尘》、王实甫《西厢记》、汤显祖《牡丹亭》、孔尚任《桃花扇》、洪昇《长生殿》。李渔的「结构第一、词采第二、音律第三、宾白第四、科诨第五、格局第六」有一部分对板腔体同样成立，建成后本 skill 的第〇之二节会补一行指向它。

缺口补进来之前，遇到板式、行当、程式、曲牌的问题**直说没有**，不要用通用层的东西硬凑。

## 二、唱词三好（陆军）

- **韵选好**：根据人物性格定韵（泼辣的李玉桃"交消"韵"回来了回来了我队长娘子李玉桃"；热心的蹄膀娘"江阳"韵；体弱温和的小艾"衣溪"韵）；根据重点句定韵（先写闪光的重点唱句——体现主题/描写心情/揭示关系变化——再由它定韵：《竹园曲》"你一个'狠'字随风过"定"乌乎"韵，铺开"廿年"排比"我为谁付出廿年血和泪"）；宽韵（人辰江阳言前，字多易写易雷同）与险韵（也斜发花，字少但贴切则耳目一新：《一夜生死恋》"癞蛤蟆……十人见了九摇头"倒数）；**同字韵**的魅力（几十个"手"、近百个"人"、"你""我"：洪医生"骗你其实是爱护你……一辈子没有一个安宁的你"）。
- **结构编织好**：忌一律七字十字；借用不同曲牌句式（"阴阳血"问答、"赋子板"叙事）；随环境与演出样式变（抬轿舞的三重唱合唱旁唱对唱）；回文可表回肠之情（"闷无心我负人，人负我心无闷"）——句式曲格力避呆板划一。
- **布局好**：忌"当唱不唱、不当唱偏唱""东唱一段西唱一段鸡零狗碎"；精心设计重点场面（男女主人公情感抒发、冲突激烈、命运转折的关键时刻）成整块音乐场面，历代流传唱段都从重场戏中凸现。

**与宾白的分工**：宾白走 `sw-dialogue` 的对话三要求（动作性／性格化／潜台词）；唱词承担抒情与转折，所以布局规则的实质是**把唱段留给价值转折最大的那一场**，这一点与 `sw-scene-craft` 的价值转折是同一件事的两种写法。

## 三、诊断清单

1. 这段唱的韵是从人物性格定的，还是顺手押的？换一个性格相反的人物来唱，韵该不该变？
2. 重点句先有了吗？韵是重点句定的，还是重点句迁就了韵？
3. 数句式：是不是一律七字或十字？有没有借曲牌句式、问答、回文打破？
4. 唱段落在重场戏上吗？把全剧唱段列出来，最长的一段是不是在价值转折最大的一场？
5. 有没有"当唱不唱"——冲突顶点用宾白滑过去了；有没有"不当唱偏唱"——过场戏也来一段？
6. 用了险韵的地方，贴切吗？不贴切就退回宽韵。

## 四、工作流程

1. 先确认是板腔体：京剧、豫剧、越剧、秦腔、评剧、沪剧、小戏走本 skill；元杂剧、传奇、昆曲是曲牌体，本 skill 不适用，直说。
2. 按 `sw-workflow` 入口路径「短片 / 小戏 / 独幕剧」那一行走通用阶段：戏核（`sw-premise-theme` 第十节）→ 起承转合与八种开头（`sw-story-structure` 第六节）→ 人物。
3. 列全剧场次，标出价值转折最大的两三场，**唱段只分配给它们**。
4. 每个唱段先写重点句，由重点句定韵，再铺开。
5. 宾白按 `sw-dialogue` 对话三要求写，唱词按第二节写；跑第三节诊断清单。
6. 板式、行当、体例的问题，在第一节缺口补入之前，明确告知用户本 skill 尚未覆盖。
