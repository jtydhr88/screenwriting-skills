# 戏曲编剧：唱词范例

> 本 reference 现在只有一节（陆军的唱词范例，自 `sw-dialogue/reference.md` 迁入）。剧种附录（京剧十三辙与板式字句表、豫剧中州韵与板式表）、剧本体例样本、大师全本拆解将按 SKILL.md 第一节的顺序补入，补一节编一节号。

## 一、陆军：唱词范例

- **定韵于性格**：李玉桃（交消）"哈哈哈！回来了回来了，啊呀呀回来了我队长娘子李玉桃，丈夫当上三十六品芝麻官扳扳指头算一算不大也不小"；蹄膀娘（江阳）"生就一副热心肠，十八岁开始做红娘，搭鹊桥配鸳鸯串村走户心欢畅……人也吃得像蹄膀，呀蹄膀娘三字名气响"；小艾（衣溪）"都说我小艾好福气，丈夫在工程队里搞设计……也觉得天伦之乐总是乐合家团聚便是喜"。
- **重点句定韵**（《竹园曲》乌乎韵）：春哥妈"一个狠字勾起我满腹怨恨满腔火……我盼呀盼盼尽了腊梅腊梅随风舞，盼红了桃花桃花落水波，盼来了新荷新荷自高洁，盼黄了秋菊秋菊也不属我……我为谁付出廿年血和泪？我为谁尝遍廿年酸与苦？我为谁忍受廿年耻与辱？我为谁强压廿年恨与怒？到头来只换得一枕黄粱两鬓斑白三江怨仇四方白眼人前背后强作奴，你一个'狠'字随风过！"
- **险韵倒数**（《一夜生死恋》）：赖阿毛"一个脑袋如木瓜二眼专找旁人岔三班倒是苦工作四肢发达却贫血五谷难分本无能六亲全断更孤独七尺男子少热情八方讨嫌多责骂九十元收入家底薄实在是十人见了九摇头"；白娥"既然是十全十美人间无九十元收入我也知足八面玲珑虽则好七尺男子重不惑六亲断了可以续五谷不分从头学四肢发达多刚健三班倒总得有人去工作二厢情愿最重要一锤定音请答复"。
- **同字韵**（《石榴裙下》）：洪医生"原谅老夫骗了你，骗你其实是爱护你，倘若当初依了你，死了雯慧害了你……良心的谴责折磨你，道德的鞭子抽打你，心灵的阴影笼罩你，一辈子没有一个安宁的你，你说要不要阻止你？"；吴妈"喜酒吃好了喜糖发过了喜钿到手了喜事办好了，客人走光了辰光勿早了，二少爷好回来了新娘子要困觉了"。
- **句式变化**（《桃园曲》抬轿）：桃花"那桃树可有病可有残可有伤来可有亡？"柳"这宝贝枝枝绿叶叶嫩根根粗来棵棵壮""想不会母鸡生疮——""此话怎讲？""毛里有病——""不敢当"……合"抬起那个轿子泪汪汪一只脚跨在棺材旁"。
- **回文**（《女贞观》）："恨多情过一春，春一过情多恨。闷无心我负人，人负我心无闷。真成假假成真，恩生怨怨生恩。"

**读法**：六组范例对应 SKILL.md 第二节的三条规则——前四组是「韵选好」（性格定韵／重点句定韵／险韵／同字韵），后两组是「结构编织好」（句式变化／回文）。「布局好」没有单独范例，因为它是全剧层面的分配问题，看的是唱段落在哪一场，不是某一段本身。
