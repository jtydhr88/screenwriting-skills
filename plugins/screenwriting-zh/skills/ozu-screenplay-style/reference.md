## 一、《晚春》（1949，103 场）

**一句话故事**：镰仓的鳏居教授周吉（56）为了让不肯出嫁的女儿纪子（27）离开自己，谎称自己要再婚；纪子在愤怒、失落之后接受相亲出嫁，父亲独自削着苹果度过婚礼之夜。

| 段落 | 场号 | 内容 | 功能 |
|---|---|---|---|
| 序 | 1–8 | 北镰仓车站、茶会、庭院日影、树莺 | 空镜建立季节与"静"；秋子第一次入画（无台词） |
| 建置 | 9–18 | 周吉与服部写稿；纪子归家；父女同乘电车 | "倒茶倒茶"确立父女关系的松弛与依赖 |
| 假线索 A | 21–26 | 银座偶遇小野寺→多喜川→说"再婚脏脏的" | 埋雷：纪子亲口否定"再婚" |
| 假线索 B | 27–30 | 与服部骑车、"藕断丝连的腌萝卜" | 让观众误以为服部是对象 |
| 第一推力 | 31–37 | 姑母怂恿父亲问纪子对服部的看法→"服部要结婚了" | 假线索破产；喜剧节奏 |
| 空白 | 38–42 | 咖啡馆退票→剧场空座→纪子独行丸之内 | 省略法：用空座位表达寂寞 |
| 对照者登场 | 43–48 | 绫来访："回门货"；同学会八卦 | "我不嫁了"第一次明说 |
| 第二推力 | 49–52 | 姑母家：提相亲→拒绝→提出让秋子给父亲做续弦 | 中点：纪子"应该可以吧，只要爸爸没意见的话"（冷淡） |
| 冷战 | 53–57 | 纪子不理父亲；"买东西……"落寞而去 | 几乎无台词 |
| 旁证 | 58–61 | 邻居收服部的结婚答谢礼 | 第三方视角确认 |
| 高潮前 | 62–66 | 能乐堂：父亲向秋子点头；纪子越来越不快 | 无台词高潮 |
| 爆发 | 67–68 | 绫家：奶油蛋糕之争 | 移置 |
| 摊牌 | 69–73 | "假如有谁来照顾爸爸"→逼问→"嗯"→冲上楼哭 | 谎言落地 |
| 松弛 | 74 | 八幡宫姑母捡钱包"这桩婚事一定成" | 喜剧调剂＋吉兆 |
| 决定 | 75–82 | 绫劝婚→答应→父亲问"不会是死了心才嫁？" | 决定是勉强的 |
| 告别之旅 | 83–93 | 京都：向小野寺道歉；龙安寺"养女儿真没意思"；旅馆夜谈→长独白 | 全片唯一长独白 |
| 尾声 | 94–103 | 婚礼日镜前→跪别→空房间→绫的吻与"漂亮的谎"→削苹果皮断→夜海 | 真相由第三者点破 |

### 范例 A：三个"嗯"（71 场）
```
纪子：那爸爸会像小野寺叔叔那样……
周吉：（含混地）嗯……
纪子：再婚吗？
周吉：嗯……
纪子：（越发尖锐地）您会再婚，对吧？
周吉：嗯。
纪子：就是今天那一位？
周吉：嗯。
纪子：真的吗？……是真的吗？
周吉：嗯。
纪子：……（渐渐不堪忍受）
突然站起来，逃走般离去。
```

### 范例 B：无台词的高潮（62 场 能乐堂）
```
周吉看着唱本，忽然向对面的某个人点头致意。
纪子觉察了，往那边望去——
是三轮秋子，坐在对面的座位上。
于是纪子也颔首致意。
秋子也优雅地默默行礼。
周吉继续注目唱本和舞台。纪子这边很介意父亲与秋子之间的交流，眼光禁不住朝向秋子的方向。
端庄秀丽的秋子注视着舞台。
虽说父亲之后没有朝秋子的方向看去，秋子也没有再看父亲这边，但纪子总觉得心中颇不平静。
显得越来越不愉快。
```

### 范例 C：移置式争吵（68 场）
```
纪子气得把已经拿在手上、还没碰过的蛋糕盘子"嘭！"地一放。
绫：不吃啊？
纪子：不想吃！
绫：请给我吃了！
纪子：我就是不想吃！
绫：跟你说好吃着呢！
纪子：够了！
绫：什么呀，这么点儿东西！我亲手做的，你给我吃了！
纪子：我偏不要！
绫：叫你给我吃！不吃也要让你吃！
纪子：我就是不要！
绫：扯什么疯！不吃就不吃！
纪子：（气得说不出话来）……
绫：我就说嘛，你就该早点嫁人算了。
```

### 范例 D：唯一的长独白（93 场，节选）
```
周吉：——爸爸已经五十六岁了，爸爸的人生已经接近尾声了，可是你们这才开始呢。……这是人类生活的历史规律啊。
……就是结了婚，或许也并不是一开始就幸福。……幸福不会等在那里，还是要靠你们自己创造才行。结婚本身不是幸福——新婚夫妇共同建起新的人生，这过程里才有幸福。……你妈妈也不是从一开始就幸福的。……爸爸曾经好几次看见她在厨房角落里哭。但你妈妈努力经受住了——
```

### 范例 E：结尾（100–103 场）
```
绫：我可撒不了那么漂亮的谎。
周吉：什么？
绫：我可撒不了那么漂亮的谎。
周吉：哈哈哈哈——（然后落寞地）没办法呀，叔叔这辈子也是头一回撒这么大的谎啊……
……
周吉独自寂寞地脱下礼服上衣，挂在门框的衣钩上。啪啪拍打上面的灰尘后，无力地走到椅子边坐下。忽然看见桌上的苹果，于是拿起来削，苹果的皮没削多长便断了。周吉就那样一动不动地坐着。

103　夜晚的海
舒缓而巨大的波浪，哗啦哗啦地涌向岸边又退去……
```

## 二、《麦秋》（1951，145 场）

**一句话故事**：北镰仓三代同堂的间宫家，28 岁的女儿纪子被董事介绍了一门"条件极好"的亲事；全家动员调查、劝说，她却在邻居寡母一句"要是你能做媳妇多好"之后，突然决定嫁给带着孩子、即将去秋田的医生谦吉。家人错愕、接受，全家合影，随后分散。

| 段落 | 场号 | 内容 | 功能 |
|---|---|---|---|
| 序 | 1–19 | 清晨全家早饭各自出门；爷爷给孙子剪指甲 | 一顿早饭建立三代七口 |
| 世界 | 20–25 | 董事办公室；绫来访；兄妹嫂吃天妇罗 | 康一"劝人喝又不让喝"由妹妹当面总结 |
| 大伯来访 | 26–45 | 耳背的茂吉；孩子喊"浑蛋"；长谷大佛；歌舞伎 | 耳背＝听不见的家人 |
| 提亲 | 40–46 | 高子夫妻吵胡萝卜；董事提亲、给高尔夫照片 | 已婚的争吵＋未婚的提亲 |
| 调查 | 47–58 | 绫母"报喜"；康一夫妇床边商量；周吉"得抓紧了" | 婚事在纪子不在场时被推进 |
| 婚宴后 | 59–61 | "幸福种族"之争；康一躲纸门后探头三次 | 兄长藏在门后指挥嫂子 |
| 信调 | 62–64 | 信用调查所来过；省二"他不会回来了" | 从喜剧沉到战争创伤 |
| 周日 | 65–75 | 鲤鱼旗；孩子铺轨道；老两口看断线的气球 | 中点空镜："现在也许是我们家最好的时候" |
| 副线爆发 | 76–105 | 蛋糕九百块；"轨道"其实是面包→踢面包→挨打→出走→找到 | 大人给的礼物不是孩子要的 |
| 转折触发 | 106–108 | 谦吉告诉母亲要去秋田 | 时间压力 |
| 决定 | 109–117 | 尼古拉教堂咖啡馆回忆省二、麦穗的信；多美一句瞎想→"要是我也行的话" | 决定的一瞬，谦吉不在场 |
| 家庭反应 | 118–121 | 深夜全家会议"肯定不会？""不会。"；父母无力上楼；纪子对镜抹口红 | 反应排队 |
| 消化 | 122–135 | 多美来公司确认；志繁抱怨；周吉铁道口叹息；绫的秋田方言；海边嫂妹"勤俭比赛" | "剪刀就在眼前" |
| 告别 | 136–140 | 全家合影＋父母单独合影；寿喜烧送别；纪子逃到二楼哭 | 合影＝家庭最后一次完整 |
| 尾声 | 141–145 | 大和麦田；老两口看别人家送嫁 | 主角不在，用别人的婚礼收束 |

### 范例 A：决定的一瞬（113 场）
```
多美：没什么，呵呵，是我自己想得美，我曾想，要是能有你这样的姑娘给谦吉做媳妇那该多好啊！
纪子：哦。
多美：对不住啊，这只是我自个儿做梦瞎想的……不许生气啊。
纪子：真的吗？阿姨——
多美：什么呀？
纪子：对我，您真的是这么想的吗？
多美：对不住啊，所以说请你别生气啊。
纪子：阿姨啊，像我这样嫁不出去的也行吗？
多美：啊？（仿佛怀疑自己听错了）
纪子：要是我也行的话……
多美：（情不自禁地）真的？（声音也大起来）
纪子：嗯。
```

### 范例 B：当事人的事后确认（117 场）
```
多美：我跟你说呀，纪子姑娘说她肯来！她说，肯到咱家来呢！
谦吉一屁股坐下，多美也坐下来——
谦吉：来哪里——
多美：来咱家啊！
谦吉：来干吗——
多美：不是来干吗！是来你这里！来做你媳妇啊！
谦吉：做媳妇？
多美：是啊，多高兴啊！太好了……
谦吉：……（愣住了）
……
谦吉：（小声地）我高兴呀。
多美：那，脸上可以更高兴一点呀。高兴吧。——你这孩子，真奇怪……

### 范例 D：空镜中的主题（75 场）
```
周吉：真快啊……康一娶亲，孙子出生，然后是纪子出嫁。也许现在才是最快乐的时候呢。
志繁：或许吧……不过今后也还……
周吉：不想了，人贪心起来也是没止境的。——啊，真是个晴朗的星期天啊……
志繁：哎，你看——（指着对面的天空）
周吉：唔？（看天空）
断了线的气球朝着空中飞去。
周吉：不知哪里，一定有个不小心放走了气球的孩子在哭鼻子吧……康一不也有过这样的时候吗……
```

## 三、《东京物语》（1953，176 场）

**一句话故事**：尾道的老夫妇周吉（70）、富子（67）上东京看望儿女，被忙碌的儿女推来推去、送去热海；只有战死次子的遗孀纪子真心接待他们。回程途中富子病倒，回家不久去世；儿女匆匆奔丧又匆匆离去，只有纪子留下。父亲把亡妻的手表送给她，劝她改嫁。

| 段落 | 场号 | 内容 | 功能 |
|---|---|---|---|
| 序 | 1–6 | 尾道早市；找气枕；邻家太太"真有福气" | 从外面看很有福气 |
| 到达 | 7–35 | 幸一家：书桌被搬到走廊；志繁带脆饼；"还以为会更热闹一点" | 儿子的家不如想象 |
| 落空的周日 | 36–52 | 幸一出诊；阿实发怒；"等你当上医生时奶奶已经不在了" | 孩子的愤怒替老人表达 |
| 志繁家 | 53–58 | 库造买点心被嫌贵；志繁打电话拜托纪子 | 把父母"外包" |
| 纪子的一天 | 59–73 | 观光巴士；公寓借酒借酒壶；昌二照片；外卖 | 唯一真诚的招待 |
| 热海 | 74–91 | 兄妹凑三千块；麻将卖唱失眠；"这是年轻人来的地方"；富子晃了一下 | 孝顺＝送走；病的伏笔 |
| 无家可归 | 92–94 | 撞上讲习会；"到底变成无家可归的了"（微笑）；上野公园嚼花生 | 中点 |
| 两条夜线 | 95–108 | 父亲酒局：沼田"股长说成部长"、"父母的私欲"；母亲在纪子处："我已经决定不长岁数了"；父亲醉倒被送回美发店 | 平行蒙太奇 |
| 离开东京 | 109–112 | 纪子给零用钱；"有个三长两短就不必特地赶回来了" | 死亡预告被笑着打断 |
| 大阪 | 113–116 | 敬三"没法往坟上盖被子，哈哈哈"；"算是有福气的了" | 第三次"有福气" |
| 病危 | 117–129 | 信到→电报到→"丧服带不带？" | 志繁的实用主义 |
| 临终 | 130–143 | 周吉扇扇子"会好的……"；幸一"能挨到天亮就不错了"；"就这么完了啊" | 医生儿子宣判母亲 |
| 黎明 | 144 | 空站台、无人街道、细浪 | 死亡在空镜里 |
| 葬礼 | 145–157 | 志繁要腰带和麻布；山崖上"多美的早晨啊"；"还是爸爸先走比较好" | 悼念与算计同桌 |
| 尾声 | 158–176 | 京子"他们太自私了"/纪子"大家都会变成那样"；手表；火车上听表；"日子变长了" | 总结给纪子；回到邻家太太 |

### 范例 A：无家可归（93–94 场）
```
周吉：再到幸一那里去添麻烦也不好……
富子：也是啊——要不到纪子那里借宿一晚？
周吉：不成，那里也住不下咱们两个。你一个人去借住吧……
富子：那你呢？
周吉：我想去服部先生那里拜访一下，应当可以让他容我住一宿——总之，那就走吧。
富子：好吧。
周吉：（微笑着）——到底变成无家可归的了……
富子也笑着点头。
……
周吉：嗨，东京可真大呀。
富子：就是。要是不小心在这地方走丢了，恐怕一辈子都找不着吧。
```

沼田：你这么觉着吗？
周吉：是这么觉着。

```

### 范例 C：母亲与纪子的夜谈（103 场）
```
富子：可是，即便现在是这样，将来渐渐上了年纪，一个人还是会寂寞的啊。
纪子：不要紧的，反正我已经决定不长岁数了。
富子：（感动得落泪）你啊……真是个好人哪……
纪子：（淡淡地）睡吧。
说完起身关灯，钻进被子。不一会儿，纪子的眼里渐渐涌出泪水。
```

### 范例 E：山崖上（149 场）

### 范例 A：镜像揭开（27 场）
```
佐久间：（依然惬意地嘟哝着）啊，愉快……太愉快了！嗯……平山！河合！
叫喊之后忽然蔫了。
伴子在一旁看着，忽然悲从中来，捂住了脸。——远处传来俗气的唱片曲……
```

### 范例 B：忏悔（57 场）
```
佐久间：唉，寂寞啊……悲哀啊。——到头来人生就是自己一个人啊……孤零零一个人啊。
河合与平山面面相觑。
佐久间：唉，我错了……我做错了一件事……我不该只图自己方便……
平山：是什么事？
佐久间：唉，我女儿啊。——我图方便，把女儿留在身边使唤……当初也不是没有去处……只因为我老婆不在了……我错了……最后错失了机会……啊呀！我该告辞了！
……
河合：你要是不小心也会变成这样。
平山：哪会啊，我……
```

### 范例 C：女儿的反将（61 场）
```
路子：这么说又能怎样呢？跟您说吧，爸爸，我现在还根本没打算嫁人呢，我才不想嫁呢。爸爸您不也是这么想的吗？
平山：想什么？
路子：想我就这样留在这里更好……
平山：为什么？不是那样的。
路子：明明就是这样的啊。我要是嫁了，爸爸和阿和怎么办呀？
平山：那总有办法的。
路子：说是总有办法，究竟该怎么办呢？怎么办都不成呀。爸爸您到底从什么时候生出这念头的？
```

### 范例 D：错过（75 场）
```
三浦：那，你应该早点儿跟我说啊……我曾经委婉地问过你的，然后你当时不是说，她一时半会儿还不会出嫁吗？
幸一：这样啊，我说过那样的话啊？
三浦：你说了啊，说了的。路子小姐也是这么说的——哎，再要一瓶啤酒吧。
幸一：哦——（按下呼铃）这样啊。真是不应该啊……
三浦：实在太可惜了，要是早点儿说给我就好了……猪排，可以再来一份吗？
```

### 范例 E：接受（77–79 场）
```
路子：（仰起脸，微笑着）没事的，爸爸……那样的话就算了……我只是不想以后后悔而已……幸亏你们帮我问了。
……
幸一：我还想，要是把她惹哭了可怎么办。
平山：唔，我也以为她会显得更失望一些呢。
幸一：没想到她并不介意似的。
平山：嗯，这就好啊。
和夫走来。
和夫：怎么回事？姐姐好像在哭呢。
平山和幸一面面相觑，平山站起身走出。
……
平山走出，去到走廊上停下来，在那里抬头看了看天，然后回到房间。
```

```

### 范例 G：结尾（92–98 场）
```
馨：今天这是从哪里回来？——葬礼吗？

……
军舰进行曲响起。
