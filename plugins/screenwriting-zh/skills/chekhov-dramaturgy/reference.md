## 一、《没有父亲的人》（普拉东诺夫，约 1880，四幕）

**一句话故事**：将军夫人安娜的庄园夏天开门迎客。乡村教师普拉东诺夫（27，昔日"拜伦第二"，如今"平放的石头"）在一夜之间被四个女人围住：妻子沙萨、安娜（骑马夜访"咱们走"）、旧情人索菲娅（已是庄园继子之妻，送来电报式的信"来把我取走"）、被他当众羞辱的姑娘格列科娃。他去了索菲娅那里；沙萨卧轨未遂、服火柴头未遂；索菲娅告诉丈夫真相；盗马贼奥辛普受雇来杀他；庄园被拍卖；普拉东诺夫用手枪对准太阳穴又放下"想活"，格列科娃来接他走，索菲娅进来开枪，第二枪顶着胸膛。最后一句："给他三个卢布！"

| 幕 | 场景/环境声 | 内容 | 功能 |
|---|---|---|---|
| 一（22 场） | 客厅，钢琴、小提琴、簧风琴 | 下棋谈格列科娃；老格拉戈列耶夫怀旧；普拉东诺夫夫妇登场；对亡父"或是说真话，或是什么也不说"；羞辱格列科娃"臭虫乙醚"又道歉；索菲娅认出他；假牙；"三条路"；小维格罗维奇拒绝握手；奥辛普被展示"现代动物博物馆的嗜血动物"；安娜"或是庄园，或是良知……我选择庄园" | 一次接待日：所有人物依次进门、被主角得罪一遍 |
| 二·一景（21 场） | 花园夜宴；九柱戏"五个好球！四个坏球！"；烟火 | 借钱撒钱；上校醉话；索菲娅"咱们离开这里吧"；"您胆怯了"；雇奥辛普"揍一顿"；格列科娃被吻被骂；"男人与女人之间的友谊离爱情只有一步之遥"；"我有天堂，但没有天使"；儿子骗父亲"她要一千卢布"→中风；"我们为什么不能像我们所应该的那样生活？！"；索菲娅"我向你祝福，新生活！"→烟火 | 一夜之间四条线全部点燃 |
| 二·二景（17 场） | 学校前，铁路路基，电线杆；夜；火车 | 奥辛普讲爱上安娜；"你为什么不是只苍蝇"；小维格罗维奇夜谈；**安娜骑马来"咱们走！"**；卡嘉送信"来把我取走。你的我"；沃依尼采夫醉"我演哈姆雷特，你演克劳狄斯"；奥辛普向天开枪；**沙萨躺到铁轨上→被抱起→火车通过** | 三个女人的召唤在同一段路基上交替 |
| 三（10 场） | 学校房间，杂物，酒瓶 | 三周后。索菲娅"明天我们走"；读安娜的信；传票→在传票上给格列科娃写信；安娜来喝酒"要像个人那样地活着，蠢人"；他关门堵耳朵；**奥辛普来杀他**：撕钞票"不让您误以为我杀您是为了钱"；沙萨"私情结束了？"→走；"把她还给我"；老格拉戈列耶夫"她是个诚实的女人吗？"→昏倒→"咱们去巴黎" | 主角在一间屋里被五个来访者轮番审判 |
| 四（13 场） | 将军书房；枪支刀剑挂满墙；早晨；雨 | "我是戴绿帽子的丈夫"跪求；奥辛普被农民打死；庄园被买下；格列科娃撤诉；普拉东诺夫手缠绷带"不要自杀……我把自己杀了"；"给我点什么热的东西"；"服火柴头自杀了！""她没有死？""活着！"（大笑）；上校"谎话有时也能解救人"；对准太阳穴"想活"；"您哪里痛？""普拉东诺夫在痛"；索菲娅开枪；"给他三个卢布！" | 所有人在同一间书房完成清算；死亡是喜剧的 |

**范例：奥辛普来杀（三幕七场）**
```
奥辛普　您想知道吗？
普拉东诺夫　得了吧！真有意思！到哪儿去呢？
奥辛普　到阴间去。
普拉东诺夫　好远！（停顿）莫非你是送我去阴间的人？
奥辛普　正是。通行证我给您带来了。
……
奥辛普　（拿出一些票子）瞧……这是维格罗维奇给的，他让我把您废了！（撕掉钞票）
普拉东诺夫　嗯……你干吗把钞票撕了？想表现一下自己的大度，是吗？
奥辛普　我不会表现大度，我撕掉钞票，是为了不让您误以为我杀您是为了钱。
```

**范例：结尾（四幕）**
```
［索菲娅拿起手枪，朝普拉东诺夫开枪，没有射中。
格列科娃　（站在普拉东诺夫和索菲娅之间）您干什么？！（大叫）来人啊！快来人啊！
索菲娅　您放开……
［绕过格列科娃，用枪口顶着普拉东诺夫的胸膛射击。
普拉东诺夫　您等一等，您等一等……为什么会是这样？（倒下）
……
马尔科　（上）调解法庭……（停顿）
安娜　普拉东诺夫！
［普拉东诺夫稍稍坐起，用眼睛扫视大家。
安娜　普拉东诺夫……这没有什么……喝点水！
普拉东诺夫　（指指马尔科）给他三个卢布！（躺下，死去）
……
特里列茨基　生命是一个戈比！米沙，永别了！你的戈比消失了！
```

## 二、《伊凡诺夫》（1887，四幕正剧）

**一句话故事**：三十五岁的乡绅伊凡诺夫，曾经狂热、理想、为爱娶了犹太女子安娜（她为他改宗、被父母抛弃），如今对一切厌倦，每晚逃到邻居列别捷夫家；邻家二十岁的女儿萨沙以"主动的爱"要拯救他；妻子撞见二人拥吻，他失控喊出"你就要死啦"；一年后妻子已死，他在与萨沙的婚礼前照镜子看见白发，要求解除婚约，被医生里沃夫当众骂作流氓，掏枪自杀。

| 幕 | 场景/环境声 | 内容 | 功能 |
|---|---|---|---|
| 一 | 庄园花园；钢琴与大提琴二重奏；猫头鹰；更夫；远处手风琴 | 鲍尔金用枪吓他、要八十二卢布；医生宣布肺痨；伊凡诺夫剖白"我没有一点不平凡之处"；忠告医生"娶个平凡暗淡的"；里沃夫独白"我恨这个达尔丢夫"；安娜求他留下，他答"替我祈祷吧" | 一幕内把所有人的病都摆出：厌倦、肺痨、吝啬、愤世、正义狂 |
| 二 | 列别捷夫家客厅；打牌声"帕斯""黑桃二"；老太太的闲话 | 萨沙生日；谣言三版本（大蒜、牛瘟、九千卢布）；萨沙痛骂青年们"你们都是废物"；久久什卡吹蜡烛；求延利息被拒；鲍尔金替伯爵向巴巴金娜求婚；**萨沙表白→"生活重新开始了"→安娜站在门口僵住→"萨拉！"幕落** | 谣言场＋吝啬场＋求婚闹剧＋幕尾撞破 |
| 三 | 书房；桌上文件与手枪、伏特加、青鱼、黄瓜；中午 | 谈法德政治吃黄瓜鲤鱼；列别捷夫拿出一万一千又收回"我刚才是逗着玩儿的"；"我把自己压出疝气"；"我恨我自己的声音、脚步、双手"；里沃夫"摘下你的面具"；萨沙"你造过假钞票吗？……砸破点东西吧"；**安娜逼问→"住嘴，你这犹太女人！……你就要死啦"→"他这是什么时候说的？"** | 主角自剖两次；最残酷的话在幕尾说出 |
| 四 | 一年后；婚礼氛围；钢琴、小提琴、大提琴 | 里沃夫"我要揭穿你"；科西赫仍在讲牌；萨沙"我甚至有时候觉得我并不像该爱他的那样爱他"；伯爵看见大提琴哭亡妻；"我照照镜子，看见我的两鬓已经发白了……就到此为止吧"；"天花板是白的，靴子是黑的，糖是甜的"；"你是一个流氓！"—"我很感谢你"；"这不是一场婚礼，而是一场辩论"；"我的青春在我的心里觉醒了"→开枪 | 婚礼变辩论会；自杀是"旧我振作"的反讽 |

**范例：三幕尾**
```
伊凡诺夫　哼，让我告诉你吧，你……你就要死啦……医生告诉我，说你就要死啦……
安娜　（坐下，低声）他这是什么时候说的？
［停顿。
伊凡诺夫　（两手抓住头）我简直是个禽兽啊！我的上帝，简直是个禽兽啊！（啜泣）
——幕落
```

**范例：列别捷夫的常识（四幕）**
```
让你的头脑冷静一下！像别人那样，把事情看得简单一点！人世间一切事情都是简单的。天花板是白的，靴子是黑的，糖是甜的。你爱萨沙，她也爱你。如果你爱她，你就留下；你不爱她，你就走；咱们用不着小题大做。
```

## 三、《海鸥》（1896，四幕喜剧）

**一句话故事**：湖边庄园。青年特里波列夫在自建的露天舞台上演自己的"新形式"剧，由他爱的少女妮娜主演；母亲、女演员阿尔卡基娜嘲笑它，他愤然闭幕。妮娜迷上母亲的情人、作家特里果林。特里波列夫打死一只海鸥献在妮娜脚下，随后自杀未遂。特里果林带妮娜私奔又抛弃她。两年后妮娜成了三流演员回来一晚，念起当年的独白后离开；特里波列夫撕稿，画外一声枪响，医生说"我的一瓶乙醚刚刚炸了"。

**爱情链（全部单向）**：麦德维坚科→玛莎→特里波列夫→妮娜→特里果林⇄阿尔卡基娜；波琳娜→多尔恩；索林想结婚想当作家都没成（"L'homme qui a voulu"）。

| 幕 | 场景/环境声 | 内容 | 功能 |
|---|---|---|---|
| 一 | 花园，业余舞台遮住湖；锤击声；狗整夜咆哮；戏中戏的号声、硫磺味、磷火 | "你为什么总是穿着黑衣裳？""我给我的生活挂孝"；戏中戏"人，狮子，鹰和鹧鸪……"被母亲用"颓废派""硫磺味"打断→"闭幕！"；"一个天使飞过去了"；多尔恩独自赞剧本；玛莎倚在多尔恩胸前"我爱康斯坦丁" | 第一句就是主题；戏中戏是全剧胚胎；幕尾改为倾诉 |
| 二 | 棒球场，中午，湖水反光 | 阿尔卡基娜与玛莎比年轻；管家为马争吵"我就辞职"；波琳娜求多尔恩带她走，弄坏花；**死海鸥放在妮娜脚下"我不久就会照着这个样子打死自己"**；特里果林长独白（浮云像三角钢琴、"比不上屠格涅夫"）；记笔记"一片湖边……住着一个像海鸥的女孩子……偶然来了一个人……把她毁灭了" | 海鸥的三层含义全部埋下；小说题材＝预言 |
| 三 | 餐室，行李箱 | 玛莎"我结婚"；纪念章"一百二十一面第十一和十二行"；母子换绷带→吵翻→和好；"一旦你需要我的生命的话，来，就拿去吧"→跪抱膝盖"你是俄罗斯唯一的希望"→（一旁）"现在我可算把他抓住了"；管家讲"奸鸡"；回来取手杖，约旅馆，长长的吻 | 一幕内三场"抓住" |
| 四 | 两年后；客厅改书房；风声；更夫梆子；圆舞曲；抓彩牌报数 | 舞台"像死人的骨头架子"；杂志没裁开他的那篇；多尔恩"热那亚的人群"→"扎烈奇娜雅在哪儿"；填草的海鸥"我不记得了"；**妮娜来："我是一只海鸥……不对"、"要有耐心，要懂得背起十字架来，要有信心"、再念"人，狮子，鹰和鹧鸪"、跑出去**；撕稿；牌局继续；**枪响→"我的一瓶乙醚刚刚炸了"→"想个法子把伊琳娜领走"** | 全部人物在牌桌旁，主角的死在画外一句谎话里 |

**范例：开场**
```
麦德维坚科　你为什么总是穿着黑衣裳？
玛莎　我给我的生活挂孝啊。我很不幸。
麦德维坚科　这是为什么？（沉默）我不懂……你身体很好，你的父亲虽然没有很多财产，可也还富足。我的生活比你困难多了。我一个月只进二十三个卢布，还要在里边扣去养老金。就是这种情形我也还不挂孝呢。
```

**范例：抓住（三幕）**
```
特里果林　我没有自己的意志……我从来也没有过自己的意志……懒散、柔弱、永远顺从，我真的生来就是叫女人们讨厌的啊！那么，领着我走吧，带着我走吧，只是，千万不要叫我离开你一步……
阿尔卡基娜　（一旁）现在我可算把他抓住了。（从容不迫地，仿佛没有刚才那回事似的）这个，如果你喜欢，你可以留下来。我今天先走，一个星期以后，你再找我去。说起来，你何必要这么匆匆忙忙的呢？
特里果林　不，咱们一起走的好。
```

**范例：结尾**
```
沙姆拉耶夫　（领着特里果林向立橱走去）我刚才跟你说的那个东西就在这儿啦……（从橱里取出那只填了草的海鸥）这是你吩咐我们做的。
特里果林　（注视着那只海鸥）我不记得了！（思索）不，我不记得了！
［后台，右方一声枪响；大家都吓得跳起来。
阿尔卡基娜　（大惊）怎么回事？
多尔恩　没什么。一定是我药箱子里什么东西爆了。不要慌。（由右门下，跟着就回来）我说得一点也没错。我的一瓶乙醚刚刚炸了。（低唱）"终于，我又见到你了，迷人的女人……"
阿尔卡基娜　（在牌桌旁坐下去）可把我吓坏了！这叫我想起了那一回，他……（两手蒙上脸）那种样子叫我的眼睛都发黑啊。
多尔恩　（翻着杂志，向特里果林）大约两个月以前，这份杂志上发表过一篇文章……一封美国来信；关于这个，我想问问你……（搂着特里果林的腰，把他拉向脚光）这个问题叫人极其发生兴趣……（低声）想个法子把伊琳娜·尼古拉耶夫娜领走。康斯坦丁·加夫里洛维奇刚刚自杀了……
——幕落
```

## 四、《林妖》（1889，四幕喜剧）→《万尼亚舅舅》（1896，"乡村生活即景剧"）

**《万尼亚舅舅》一句话故事**：退休教授谢列勃里雅科夫携年轻妻子叶列娜住进前妻的庄园，打乱了万尼亚舅舅和外甥女索尼雅二十五年来为供养教授而辛苦劳作的秩序；万尼亚迷恋叶列娜，医生阿斯特罗夫也被她吸引而荒废了森林和病人，索尼雅暗恋医生六年无望；教授宣布要卖掉庄园，万尼亚爆发，向教授开枪两次未中；教授夫妇离去，医生离去，万尼亚和索尼雅回到账簿前——"我们会休息下来的"。

| 幕 | 场景/环境声 | 内容 | 功能 |
|---|---|---|---|

## 五、《三姊妹》（1900，四幕正剧）

**一句话故事**：外省小城，将军的三个女儿奥尔加（教员）、玛莎（嫁了中学教员）、伊里娜（二十岁）和哥哥安德烈梦想回莫斯科；炮兵连的军官们是他们唯一的谈话对象。安德烈娶了小市民娜达莎，她一间一间占领房子，把老乳母赶走，与自治会主席私通；安德烈赌输了钱抵押了房子；玛莎爱上有疯妻的中校威尔什宁；伊里娜答应嫁给不爱的屠森巴赫男爵、去砖窑工作；军队调走那天，索列尼在决斗中打死男爵；军乐远去，三姊妹靠在一起："我们要活下去。"

**范例：柜橱演说（一幕）**
```
加耶夫　……非常可爱、又非常可敬的柜橱啊！这一百多年以来，你一直都在朝着正义和幸福的崇高目标前进，啊，你呀！我向你致敬……
［停顿。
罗巴辛　是的……
柳鲍芙　你真是一点也没有改变，列尼亚。
加耶夫　（有一点窘）打白球下角兜，蹭红球进中兜！
```

**范例：琴弦（二幕）**
```
［大家都坐在那里，一动也不动，各人想各人的心事，一片寂静。只听见费尔斯在嘟囔着。忽然间，远处，仿佛从天边传来了一种类似琴弦绷断的声音，然后忧郁而缥缈地消逝了。
柳鲍芙　这是什么？
罗巴辛　不知道，也许是哪儿矿里的一个吊桶断了。不过是很远很远的地方了。
加耶夫　也许是一种什么鸟……比如鹭鸶什么的。
特罗费莫夫　也许是一只猫头鹰……
柳鲍芙　（发抖）这声音可有点怕人！
［停顿。
费尔斯　在那一次大灾难发生以前，也整整是这个样子；猫头鹰也叫了，铜茶炉也不住地咕噜咕噜响。
加耶夫　在什么大灾难以前哪？
费尔斯　就是解放农奴以前啊。
```

**范例：卖了（三幕）**
```
柳鲍芙　樱桃园卖了吗？
罗巴辛　卖了。
柳鲍芙　谁买的？
罗巴辛　我。
［停顿。
［柳鲍芙·安德烈耶夫娜心里一阵难受，要不是她扶住了身旁的一张桌子和一把圈椅，早就会倒在地上了。瓦里雅从腰带上把那串钥匙解下来，往小客厅当中的地上一扔，就走了。
　　是我买的。我请你们等一等，不要忙，我的头有点晕，我说不出话来……
……
　　喂！音乐家们，奏吧！我很想听听你们的演奏呀！让大家都来看看我，来看看叶尔莫拉伊·罗巴辛用斧子砍这座樱桃园吧！都来看看这些树木一根一根地往下倒吧！……奏起来呀，音乐！
［乐队奏乐，柳鲍芙·安德烈耶夫娜瘫坐在一把椅子上，伤心地哭着。
　　（斥责的口气）谁叫你不听我的话的呀！我的可怜的、善良的柳鲍芙·安德烈耶夫娜呀！事到如今，可已经太晚啦。（眼里含着泪）啊！要是能够把现在的一切都结束了，可多么好哇！
```

**范例：没有发生的求婚（四幕）**
```
罗巴辛　去年这个时候，已经下雪了，这你也许还记得。可是现在呢，你看，天气又晴朗，到处又都是太阳。只是稍许冷了一点……已经降到零下三度了。
瓦里雅　我没有寒暑表。
［停顿。
　　而且寒暑表也破了……
［停顿。
［门外院子里的人声："叶尔莫拉伊·阿列克塞耶维奇！"
罗巴辛　（好像老早就只盼望有人这么一叫似的）我就来！（急急忙忙下）
［瓦里雅坐在地板上，把头伏在衣服包裹上，轻声地啜泣。门开了，柳鲍芙·安德烈耶夫娜小心翼翼地走进来。
柳鲍芙　怎么？
［停顿。
　　那，就走吧！
```

**范例：结尾**
```
［他们都下去了，舞台上空无一人。只听见外边一道道的门在陆续下锁的声音，接着，马车赶着走远的声音。一片寂静。在这种寂静中，响起斧子砍到树上的沉闷的声音，凄凉、悲怆。
［传来脚步声。费尔斯出现在右边门口。他依然穿着那件燕尾服，白背心，可是脚下拖着拖鞋。他病了。
费尔斯　（走到左边门口，转一转门扭）锁了，他们都走了……（坐在长沙发上）他们都把我忘了……这没有关系……我就坐在这儿等好了。列昂尼德·安德烈耶维奇，一定又忘了穿皮大衣，准是穿他那件薄外套走的……（叹了一口气，挂念地）这都是我没有照顾到啊！……年轻的嫩小子啊！（又咕噜了一些叫人听不清楚的话）生命过去得真快啊，就好像我从来还没有活过一天儿似的……（躺下）我要躺下……你怎么身上一点力量都没有啦！什么都完了，都完了……哎，你呀，你……这个不成器的东西啊！……（一动也不动地躺在那里）
［远处，仿佛从天边传来了一种琴弦绷断似的声音，忧郁而缥缈地消逝了。又是一片寂静。打破这个静寂的，只有园子的远处，斧子在砍伐树木的声音。
——幕落
```

## 七、独幕剧原文范例

**赊账的递降与斧头没落下（《大路上》）**
```
提洪　（看了一遍）哼……便帽的种类多了……看这些洞眼儿，倒是一个筛子……
……
提洪　你大衣底下有什么？（往它底下看）你光光的身子，别脱，我不要……我还不想要我的魂灵儿担当罪过。
……
包耳曹夫　……可是要当心……别叫你的手指头碰那张脸……当心……我对你粗鲁，亲爱的朋友，我是一个傻瓜，不过，原谅我，千万不要拿你的手指头碰它……别拿你的眼睛看那张脸。
……
麦芮克　那么，该死的女人，恶魔送你上路！
［他摇起他的斧子。全体骚动。人人跃起，乱嚷嚷，发出恐怖的叫喊。……经过这么一闹，大家站直了，全像石头。一阵长久的沉默。
……
麦芮克　（垂下手，他仍然握着他的斧子）我杀了她，还是没有杀？
提洪　谢谢上帝，你的头牢靠啦！……
麦芮克　那么，我没有杀她……（蹒跚向他的床位）因为这是一把偷来的斧子，命运没有把我打发到死路上去……（倒下，哭泣）
```

**自由的独白（《论烟草有害》1902）**
```
跑开，样样丢在后头，看也不朝后看一眼……到哪儿去？随便哪儿都成……只要我能够远远离开这愚蠢，卑鄙，廉价的生活……远远离开，然后，在什么地方停住，在田里，静静地站着像一棵树，像一根柱子，像一家园子的纸扎人，在光天化日之下，一整夜望着头上亮晶晶的静静的月亮，忘记，忘记……（脱掉大礼服）为了慈善的目的，我总穿着这件礼服讲演……看我踏不烂你！（踩着礼服）……（向后看，急忙穿好大礼服）内人在讲台后头……她来了，在那儿等我……
```
